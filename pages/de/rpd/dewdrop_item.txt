====== Tautropfen ======

{{ rpd:images:dewdrop_item.png|Tautropfen }}

**Tautropfen** ist ein Verbrauchsgegenstand in Remixed Dungeon, der beim Verzehren eine kleine Menge Gesundheit wiederherstellt.

==== Beschreibung ====
Ein kristallklarer Tautropfen, der beim Verzehren eine kleine Menge Heilung gewährt. Diese werden häufig beim Zerstören von hohem Gras gefunden, besonders wenn man einen Ring der Kräuterkunde trägt.

==== Eigenschaften ====
  * **Typ:** Verbrauchsgegenstand (Nahrung)
  * **Heilung:** Stellt `1 + (Tiefe - 1) / 5` (+ Tau-Boni) HP pro Tropfen wieder her, bis zum maximalen fehlenden HP; Stapelmenge multipliziert den Basiswert (`min(fehlendeHP, wert * anzahl)`)
  * **Gewicht:** 0 (kein Gewicht)
  * **Stapelbar:** Ja

==== Erwerb ====
  * Wird beim Zerstören von hohem Gras gefunden
  * Chance erhöht sich mit dem Ring der Kräuterkunde
  * Kann gelegentlich von bestimmten Gegnern fallen gelassen werden
  * Manchmal in Truhen zu finden

==== Verwendung ====
  * Kann direkt verzehrt werden, um Gesundheit wiederherzustellen
  * Bietet Notheilung in gefährlichen Situationen
  * Besser als nichts, wenn die Gesundheit niedrig ist und keine anderen Heilgegenstände verfügbar sind

==== Strategie ====
Tautropfen sind nützlich für kleinere Heilungen und sollten eingesammelt werden, wenn sie gefunden werden. Obwohl sie keine große Heilung bieten, können sie in Notfällen lebensrettend sein, wenn keine anderen Heilgegenstände verfügbar sind.
