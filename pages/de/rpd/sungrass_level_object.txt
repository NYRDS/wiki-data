====== Sungrass Level Object ======

{{ rpd:images:sungrass_level_object.png|Sungrass Level Object }}

==== Beschreibung ====
Das Sungrass Level Object bietet jedem Charakter, der es berührt, Heilung über Zeit. Wenn ein Charakter auf das Feld mit einem Sungrass Level Object tritt, beginnt es einen Heilungseffekt über mehrere Züge zu bieten.

==== Effekte ====
  * Bietet dem berührenden Charakter Heilung über Zeit
  * Bietet anhaltende Gesundheitswiederherstellung
  * Der Heilungseffekt hält über mehrere Züge an
  * Das Level Object verschwindet nach der Berührung

==== Mechanik ====
  * Sungrass Level Objects können im Kerker wachsen
  * Sie können auch durch das Pflanzen von [[de:rpd:sungrass_seed_item|Sungrass Samen]] angebaut werden
  * Der Heilungseffekt tritt über eine Dauer nach der Berührung ein
  * Besonders wertvoll, wenn die Gesundheit niedrig ist

==== Strategie ====
  * Sungrass Level Objects sind extrem wertvoll zur Heilung bei niedriger Gesundheit
  * Sie sind in manchen Situationen effektiver als sofortige Heilung
  * Erwäge, sie für den Zeitpunkt aufzusparen, an dem Heilung am dringendsten benötigt wird
  * Besser als sofortige Heilung, wenn du Zeit hast, den Effekt wirken zu lassen
