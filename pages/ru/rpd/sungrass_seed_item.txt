====== Семена Солнечника ======

{{ rpd:images:sungrass_seed_item.png|Семена Солнечника }}

**Семена Солнечника** — это [[ru:rpd:seed_item|семена]], которые можно найти в Remixed Dungeon. Их можно посадить для выращивания [[ru:rpd:sungrass_level_object|Солнечника]] или использовать в алхимии для создания [[ru:rpd:potion_of_healing_item|Зелья Исцеления]].

==== Обзор предмета ====
  * **Тип:** [[ru:rpd:seed_item|Семена]]
  * **Редкость:** Обычные (встречаются регулярно по всему подземелью)
  * **Использование:** Можно посадить в [[ru:rpd:high_grass|Высокой траве]] или скрафтить в [[ru:rpd:potion_of_healing_item|Зелье Исцеления]] через [[ru:rpd:alchemy_mechanic|алхимию]]

==== Получение ====
  * Выпадают у различных [[ru:rpd:mobs|врагов]] по всему подземелью
  * Находятся в [[ru:rpd:chests_mechanic|сундуках]] и [[ru:rpd:shops_mechanic|магазинах]]
  * Растут естественно из [[ru:rpd:high_grass|Высокой травы]] при топтании
  * Можно получить через процессы [[ru:rpd:alchemy_mechanic|алхимии]]

==== Механика ====
  * **Посадка:** Можно посадить в [[ru:rpd:high_grass|Высокую траву]] для выращивания [[ru:rpd:sungrass_level_object|Солнечника]]
  * **Алхимия:** Используется как ингредиент для крафта [[ru:rpd:potion_of_healing_item|Зелья Исцеления]] в [[ru:rpd:alchemy_pot_level_object|Алхимическом котле]]
  * **Сохранение семян:** Если оставить несъеденные семена на полу при переходе на другой уровень, они сохранятся
  * **Генерация подземелья:** Часто встречаются на ранних уровнях

==== Рецепты алхимии ====
  * **Зелье Исцеления:** 1 [[ru:rpd:sungrass_seed_item|Семена Солнечника]] + Вода = 1 [[ru:rpd:potion_of_healing_item|Зелье Исцеления]]

==== Стратегия ====
  * **Экономия:** Поскольку семена расходуются при посадке и топтании, важно экономить их в начале игры
  * **Эффективность зелий:** Необходимы для создания [[ru:rpd:potion_of_healing_item|Зелья Исцеления]], одного из самых важных расходников
  * **Стратегия посадки:** Сажайте в местах, где планируете отдыхать, чтобы обеспечить доступность [[ru:rpd:potion_of_healing_item|Зелья Исцеления]]
  * **Идентификация семян:** Идентифицируются по имени при подборе или когда видны в инвентаре после идентификации

==== Эффект ====
При посадке в [[ru:rpd:high_grass|Высокую траву]] Семена Солнечника вырастут в растение [[ru:rpd:sungrass_level_object|Солнечник]], которое можно собрать, чтобы получить еще одно семя и [[ru:rpd:potion_of_mending_item|Зелье Заживления]].
