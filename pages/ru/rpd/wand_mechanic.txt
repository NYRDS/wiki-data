====== Посохи ======
{{ rpd:images:wand_of_magic_missile_item.png|Посох }}

**Посохи** - это магическое снаряжение в Remixed Dungeon, которое может быть использовано как оружие дальнего боя, но в основном применяется для [[ru:rpd:spell|заклинаний]] с расходом зарядов.

==== Типы посохов ====
  * [[ru:rpd:wand_of_magic_missile_item|Посох магических стрел]] - начальный посох [[ru:rpd:mage_class|Мага]]
  * [[en:rpd:wand_of_lightning_item|Посох молнии]]
  * [[en:rpd:wand_of_firebolt_item|Посох огня]]
  * [[en:rpd:wand_of_frost_item|Посох холода]]
  * [[en:rpd:wand_of_regrowth_item|Посох роста]]
  * [[en:rpd:wand_of_poison_item|Посох дымовой бомбы]]
  * [[en:rpd:wand_of_flock_item|Посох стада]]
  * [[en:rpd:wand_of_amok_item|Посох яда]]
  * [[en:rpd:wand_of_slowness_item|Посох буйства]]

==== Механика посохов ====
  * **Заряды:** Посохи имеют ограниченное количество зарядов, которые восстанавливаются со временем
  * **Улучшение:** Можно улучшить с помощью Свитка улучшения
  * **Идентификация:** Неизвестный посох требует идентификации для определения типа
  * **Классовая синергия:** [[ru:rpd:mage_class|Маг]] получает бонусы при использовании посохов

==== Использование ====
  * Нажмите на посох в панели действий чтобы использовать
  * Наведите на цель чтобы прицелиться (если применимо)
  * Посохи можно использовать как оружие дальнего боя

==== Эффективность ====
  * Уровень посоха увеличивает его эффективность
  * [[ru:rpd:mage_class|Маг]] получает бонусы от магической силы для всех посохов
  * Некоторые посохи имеют уникальные свойства

==== Получение ====
  * Посохи можно найти в сундуках, у врагов или в магазинах
  * [[ru:rpd:mage_class|Маг]] начинает с уникальным [[ru:rpd:wand_of_magic_missile_item|Посохом магических стрел]]
