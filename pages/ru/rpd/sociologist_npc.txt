====== Социолог ======

{{ rpd:images:sociologist_npc_mob.png|Социолог }}

**⚠️ Примечание:** Этот NPC был удален из игры (удален полностью как "мертвый промо-заглушка" согласно MobFactory.java). Java-класс `SociologistNPC.java` больше не существует. Эта страница сохранена только для исторической справки.

==== Описание ====
**Социолог** был NPC персонажем в Remixed Dungeon, который спрашивал, хочет ли игрок принять участие в опросе. Этот персонаж был частью игровой функции, позволяющей игрокам получить доступ к содержимому опроса.

==== Местоположение ====
  * Раньше встречался случайным образом на уровнях подземелья (до удаления)

==== Взаимодействия ====
  * При приближении предлагал диалог, в котором спрашивал игрока, хочет ли он принять участие в опросе
  * Если игрок соглашался, запрашивал интернет-разрешение для загрузки содержимого опроса
  * Если игрок отказывался, NPC оставлял игрока в покое

==== Реализация (историческая) ====
  * **Бывший Java класс:** SociologistNPC.java (удален)
  * **Базовый класс:** ImmortalNPC
  * **Поведение:** Реализовывал интерфейсы DownloadStateListener.IDownloadComplete и InterstitialPoint для обработки загрузки опросов с GitHub
