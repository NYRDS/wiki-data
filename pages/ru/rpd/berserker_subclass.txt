====== Берсеркер ======
{{ rpd:images:warrior_berserker_hero.png|Берсеркер }}

**Берсеркер** — это подкласс Воина в Remixed Dungeon. Этот путь мастерства фокусируется на боевом стиле с высоким риском и высокой наградой, становясь значительно мощнее, когда герой тяжело ранен.

==== Разблокировка ====
Подкласс Берсеркер можно разблокировать, используя [[ru:rpd:tome_of_mastery_item|Том Мастерства]] после победы над вторым боссом (Тенгу). Том Мастерства обычно выпадает при победе над вторым боссом (Тенгу) в подземелье.

==== Особенности ====
Когда герой тяжело ранен (ниже 40% здоровья), Берсеркер входит в состояние дикой [[ru:rpd:fury_buff|Ярости]], значительно увеличивая свой урон (урон атаки удваивается). Бафф [[ru:rpd:fury_buff|Ярость]] автоматически применяется, когда здоровье Берсеркера падает ниже 40%, пока у него еще есть HP, и исчезает, когда здоровье поднимается выше 40% снова.

==== Специальная броня ====
Использование [[ru:rpd:armor_kit_item|Набора для брони]] на любой броне превратит её в [[ru:rpd:berserker_armor_item|Броню Берсеркера]], специально разработанную для этого подкласса. Эта броня дает специальные способности, которые хорошо работают с боевым стилем Берсеркера.

==== Преимущества ====
  * Огромный рост урона при низком здоровье (в 2 раза урон атаки)
  * Может превратить ситуации на грани смерти в наступательные возможности
  * Очень эффективно для добивания боев, когда здоровье низкое
  * Самостоятельный боевой потенциал в состоянии Ярости

==== Недостатки ====
  * Активируется только при тяжелом ранение
  * Требует получения урона для входа в состояние берсерка
  * Может поощрять безрассудную игру для триггера способности
  * Уязвим при высоком здоровье (нет баффа Ярость)

==== Стратегия ====
  * Используйте рост урона, тщательно управляя [[ru:rpd:health_mechanic|здоровьем]]
  * Старайтесь держать здоровье низким (но не слишком низким), чтобы поддерживать бафф [[ru:rpd:fury_buff|Ярость]]
  * Будьте осведомлены о пороге 40% здоровья для эффекта [[ru:rpd:fury_buff|Ярости]]
  * Рассмотрите защитные предметы, которые позволяют получать урон, максимизируя время действия [[ru:rpd:fury_buff|Ярости]]
  * Используйте увеличенный урон для быстрого устранения угроз в состоянии [[ru:rpd:fury_buff|Ярости]]
  * Балансируйте риск и награду для оптимизации преимуществ подкласса
