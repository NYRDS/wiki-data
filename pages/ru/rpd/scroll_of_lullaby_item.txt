====== Свиток Колыбельной ======

{{ rpd:images:scroll_of_lullaby_item.png|Свиток Колыбельной }}

Свиток Колыбельной — это магический предмет, который усыпляет ближайших врагов.

==== Описание ====
При чтении свиток испускает успокаивающую мелодию, которая погружает всех видимых врагов в глубокий волшебный сон. Спящие враги остаются в этом состоянии, пока не получат урон или не будут потревожены.

==== Эффекты ====
  * **Область действия**: Все видимые враги в пределах видимости
  * **Длительность сна**: Определяется эффектом сна (Sleep buff)
  * **Мирный сон**: Спящие враги не атакуют, пока не получат урон
  * **Пробуждение**: Атаки или повреждения пробуждают спящих

==== Стратегия ====
  * **Безопасный проход**: Позволяет безопасно пройти опасные участки
  * **Механизм побега**: Полезен для побега из опасных ситуаций
  * **Время использования**: Лучше использовать при окружении несколькими врагами
  * **Осторожность**: Будьте осторожны, чтобы не разбудить спящих врагов

==== Код ====
Пакет: `com.watabou.pixeldungeon.items.scrolls.ScrollOfLullaby`

==== Проверка данных ====
  * Источник: Java-класс `ScrollOfLullaby.java`
  * Эффект проверен: Применяет Sleep buff ко всем видимым мобам
  * Описание соответствует строковым ресурсам
