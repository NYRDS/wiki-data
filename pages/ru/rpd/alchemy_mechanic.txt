====== Алхимия ======

Алхимия — это система крафта предметов с использованием Алхимического котла в Remixed Dungeon.

==== Описание ====
Алхимия позволяет игрокам создавать новые предметы, комбинируя ингредиенты в котле с водой. Она предоставляет способ создания расходников, улучшения существующих предметов или создания совершенно новых.

==== Места алхимии ====
  * **Алхимические зелья** — Находятся на уровне Тюрьмы и глубже
  * **Источники воды** — Используются для начала процесса алхимии
  * **Ингредиенты** — Различные предметы могут использоваться как компоненты алхимии

==== Общие рецепты ====
  * **Зелья:** Семена в сочетании с водой для создания зелий
  * **Улучшенная еда:** Семена в сочетании с едой
  * **Специальные предметы:** Уникальные комбинации для редких предметов
  * **Дальнобойное оружие:** Создание специальных стрел через комбинирование предметов

==== Механика алхимии ====
  * **Требование воды:** Большинство рецептов требуют воды для начала
  * **Комбинации ингредиентов:** Конкретные предметы должны быть объединены в правильном порядке
  * **Взаимодействие с котлом:** Предметы помещаются в котел для обработки
  * **Разнообразие результатов:** Различные комбинации дают разные результаты
