====== Система Баллистика ======

**Система Баллистика** — это система прямой видимости и поиска путей, используемая в Remixed Dungeon для определения того, может ли дальнобойная атака попасть в цель.

==== Описание ====
Система Баллистика используется для расчёта прямой видимости между двумя точками в подземелье и для определения допустимых путей для дальнобойных атак, снарядов и способностей молниеносного удара. Название происходит от итальянского слова "ballistica" — баллистика.

==== Механика ====
  * **Прямая видимость (LoS):** Определяет, есть ли неперекрытый путь между атакующим и целью
  * **Расчёт пути:** Находит потенциальный путь для прямых дальнобойных атак
  * **Ограничение дальности:** Устанавливает максимальную эффективную дальность дальнобойных способностей
  * **Обработка препятствий:** Учитывает стены, двери и другие препятствия окружения

==== Использование ====
  * **Атаки молнией:** Используется для определения, может ли моб с молнией (например, Чернокнижник) попасть по цели
  * **Использование палочек:** Определяет допустимые цели для палочек
  * **Метательное оружие:** Используется для прицеливания дальнобойным оружием
  * **Срабатывание ловушек:** Некоторые ловушки используют Баллистику для обнаружения активации

==== Технические детали ====
  * **Длина пути:** Возвращает длину расчитанного пути
  * **Обнаружение препятствий:** Останавливает поиск пути при встрече с блокирующим ландшафтом
  * **Прямой линейный путь:** Расчитывает прямые линейные пути с учётом геометрии подземелья
