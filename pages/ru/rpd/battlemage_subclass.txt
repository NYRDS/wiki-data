====== Боевой маг ======
{{ rpd:images:mage_battlemage_hero.png|Боевой маг }}

==== Описание ====
Боевой маг — это подкласс для класса [[ru:rpd:mage_class|Маг]] в Remixed Dungeon. Когда Боевой маг сражается с жезлом в руке, он наносит дополнительный урон в зависимости от текущего количества зарядов. Каждый успешный удар восстанавливает 1 заряд этому жезлу.

==== Способности ====
  * **Урон жезлом:** Дополнительный урон, равный текущим зарядам жезла
  * **Зарядка жезла:** Каждый успешный удар восстанавливает 1 заряд экипированному жезлу
  * **Боевая магия:** Эффективно сочетает магию и ближний бой

==== Специализация ====
  * Фокусируется на использовании жезлов в качестве оружия
  * Использует жезлы и как магические инструменты, и как боевое оружие
  * Сочетает кастование с физическим боем через усиление жезла

==== Лор ====
Подкласс Боевого мага представляет воинов-магов фэнтезийного лора, овладевших искусством использования магии в качестве прямого оружия в бою, а не просто для утилиты.

==== Получение ====
Подкласс Боевого мага можно разблокировать, прочитав Том Мастерства после победы над вторым боссом, Тенгу. Он доступен только для класса Маг.

==== Снаряжение ====
  * Специальная броня: [[en:rpd:battle_mage_armor_item|Броня Боевого мага]] может быть получена с помощью [[ru:rpd:armor_kit_item|Набора для брони]] на любой обычной броне
  * Предпочтительные предметы: [[ru:rpd:wand|Жезлы]], свитки для оружия, кольца усиления боя

==== Стратегия ====
  * Фокусируйтесь на использовании жезлов в качестве оружия в дополнение к их обычным функциям
  * Поддерживайте заряды жезла через успешные удары, чтобы держать урон высоким
  * Стройте билд в сторону магического боевого стиля, используя синергию с жезлами
  * Используйте бонус урона жезла, который масштабируется с текущими зарядами
