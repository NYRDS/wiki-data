====== Свиток ======

{{ rpd:images:scroll_holder_item.png|Свиток }}

==== Описание ====
Свитки — это расходные предметы, которые дают различные магические эффекты при чтении. У каждого свитка свой уникальный эффект, и они могут быть идентифицированы различными способами.

==== Основные свитки ====
  * [[ru:rpd:scroll_of_identify_item|Свиток Идентификации]] — идентифицирует предметы
  * [[ru:rpd:scroll_of_teleportation_item|Свиток Телепортации]] — телепортирует в случайное место
  * [[ru:rpd:scroll_of_remove_curse_item|Свиток Снятия Проклятия]] — снимает проклятия с предметов
  * [[ru:rpd:scroll_of_magic_mapping_item|Свиток Магического Картографирования]] — картографирует текущий уровень
  * [[ru:rpd:scroll_of_recharging_item|Свиток Подзарядки]] — подзаряжает посохи и другие предметы
  * [[ru:rpd:scroll_of_lullaby_item|Свиток Колыбельной]] — усыпляет врагов
  * [[ru:rpd:scroll_of_psionic_blast_item|Свиток Псионического Взрыва]] — наносит урон всем врагам на уровне
  * [[ru:rpd:scroll_of_mirror_image_item|Свиток Зеркального Образа]] — создаёт зеркальные копии игрока
  * [[ru:rpd:scroll_of_terror_item|Свиток Ужаса]] — пугает врагов
  * [[ru:rpd:scroll_of_challenge_item|Свиток Вызова]] — заставляет врагов атаковать героя
  * [[ru:rpd:scroll_of_weapon_upgrade_item|Свиток Улучшения Оружия]] — улучшает оружие и добавляет зачарование
  * [[ru:rpd:scroll_of_upgrade_item|Свиток Улучшения]] — улучшает предмет
  * [[ru:rpd:scroll_of_mind_vision_item|Свиток Зрения Разума]] — позволяет видеть сквозь стены

==== Механика ====
  * Свитки можно идентифицировать, прочитав их или с помощью определённых предметов/способностей
  * Чтение свитка расходует его и активирует эффект
  * Идентифицированные свитки можно использовать напрямую для их эффекта
  * Большинство свитков становятся «Неклассифицированными», когда игрок ещё не видел их
  * У неидентифицированных свитков случайные названия

==== Идентификация ====
  * [[ru:rpd:alchemy|Алхимия]] — может использоваться для идентификации свитков через варку
  * [[ru:rpd:scroll_of_identify_item|Свиток Идентификации]] — идентифицирует другой предмет
