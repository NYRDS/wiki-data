====== Гнилоягодник (Объект Уровня) ======

{{ rpd:images:rotberry_level_object.png|Гнилоягодник }}

**Объект Уровня Гнилоягодник** — это особое растение, растущее в подземелье. Ягоды этого куста имеют сладкий привкус смерти. При взаимодействии Гнилоягодник производит токсичный газ и выбрасывает другое [[ru:rpd:rotberry_seed_item|Семя Гнилоягодника]].

==== Эффекты ====
  * Производит облако токсичного газа (100 единиц) в месте растения
  * Вызывает временный эффект корней (3 хода) на персонаже, взаимодействующем с ним
  * Выбрасывает [[ru:rpd:rotberry_seed_item|Семя Гнилоягодника]] при активации
  * Растение исчезает после активации

==== Механика ====
  * Объекты Гнилоягодника можно найти растущими в подземелье
  * Их также можно вырастить, посадив [[ru:rpd:rotberry_seed_item|Семена Гнилоягодника]]
  * При активации генерируют токсичный газ, который может навредить игроку или врагам
  * Дают доступ к дополнительным [[ru:rpd:rotberry_seed_item|Семенам Гнилоягодника]] для посадки

==== Стратегия ====
  * Объекты Гнилоягодника опасны, но могут быть полезны при стратегическом использовании
  * Используйте токсичный газ для нанесения урона врагам, оставаясь вне облака газа
  * Эффект корней временный, но может быть неудобен в бою
  * Рассмотрите использование газа для очистки групп слабых врагов
  * Сажайте семена в безопасных зонах для создания собственных газовых ловушек
