====== Разбойничий Комбинезон (Броня Убийцы) ======

{{ rpd:images:rogue_assassin_hero.png|Броня Убийцы }}

**Разбойничий Комбинезон** (обычно называемый **Броня Убийцы**) — это классовая броня, получаемая при использовании [[ru:rpd:armor_kit_item|Набора для Брони]] на любой обычной броне для подкласса [[ru:rpd:assassin_subclass|Убийца]] в Remixed Dungeon.

==== Получение ====
  * Используйте [[ru:rpd:armor_kit_item|Набор для Брони]] на любой обычной броне, играя за [[ru:rpd:rogue_class|Разбойника]], выбравшего подкласс [[ru:rpd:assassin_subclass|Убийца]]
  * Преобразует базовую броню в Разбойничий Комбинезон со специальными свойствами

==== Особенности ====
  * Наследует все свойства [[ru:rpd:rogue_armor_item|Разбойничьего Комбинезона]] (способность ДЫМОВАЯ ШАШКА)
  * **Способность ДЫМОВАЯ ШАШКА:** Позволяет носителю телепортироваться в выбранную точку в поле зрения, используя действие «ДЫМОВАЯ ШАШКА»
  * Требует очков мастерства для использования специальной способности
  * Эксклюзивно для подкласса [[ru:rpd:assassin_subclass|Убийца]] — не может быть экипирована, если не выбран подкласс [[ru:rpd:assassin_subclass|Убийца]]
  * Работает в синергии с механикой удара в спину подкласса

==== Использование ====
  * Необходимая броня для максимальной эффективности подкласса [[ru:rpd:assassin_subclass|Убийца]]
  * Должна быть изготовлена как можно раньше после выбора подкласса [[ru:rpd:assassin_subclass|Убийца]]
  * Позволяет полностью использовать способности подкласса

==== Особая способность: ДЫМОВАЯ ШАШКА ====
  * Позволяет телепортироваться в целевую точку в поле зрения (пустая, проходимая клетка в поле зрения)
  * Требует очков мастерства для активации (потребляет 1 ход)
  * Может использоваться для побега из опасных ситуаций или репозиционирования для атак
  * Действие «ДЫМОВАЯ ШАШКА» ослепляет врагов, видимых носителем, на 2 хода и заставляет их блуждать
  * Можно телепортироваться только в пустые клетки в поле зрения

==== Примечания ====
  * Игровое название — «разбойничий комбинезон» (русский) / «rogue garb» (английский) — название страницы вики использует «Броня Убийцы» для ясности
  * Название класса в коде — `AssasinArmor` (одна 's') — это фактическое название класса в кодовой базе
  * Часть системы идентичности подклассов в Remixed Dungeon
  * Классовые брони представляют уникальную природу каждого подкласса
  * Не может быть надет персонажами, не разблокировавшими соответствующий подкласс
  * Наследует особую способность базовой [[ru:rpd:rogue_armor_item|Разбойничьей брони]] (телепортация ДЫМОВОЙ ШАШКОЙ с ослепляющим эффектом)
