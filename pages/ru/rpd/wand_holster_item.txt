====== Чехол для палочек ======

{{ rpd:images:wand_holster_item.png|Чехол для палочек }}

**Чехол для палочек** — это предмет-сумка, позволяющий компактно хранить волшебные палочки.

==== Описание ====
Изящное изделие, сработанное из кожи экзотического зверя. Оно обеспечивает удобное хранение для магических палочек.

==== Характеристики ====
  * **Тип**: Сумка / Контейнер
  * **Ёмкость**: Вмещает до настраиваемого количества палочек
  * **Цена**: 50 золота
  * **Складываемый**: Нет

==== Получение ====
  * Находится в сундуках подземелья
  * Доступен в магазинах

==== Механика ====
  * Расширяет класс Bag для управления инвентарём
  * Специально предназначен для хранения палочек
  * Ёмкость определяется конфигурацией
