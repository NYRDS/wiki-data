====== Механика поведения ИИ ======

**Механика поведения ИИ** относится к системам искусственного интеллекта, которые контролируют, как неигровые персонажи (NPC) и монстры ведут себя в Remixed Dungeon. Система ИИ реализована в виде состояний, которые могут динамически меняться в процессе игры.

==== Код системы ИИ ====

Система ИИ реализована с использованием интерфейса [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/ai/AiState.java|AiState]]:

<code java>
// In AiState.java
public interface AiState {
    void act(@NotNull Char me);
    String status(Char me);
    String getTag();
    void gotDamage(Char me, NamedEntityKind src, int dmg);
    void onDie(@NotNull Char me);
}
</code>

==== Основные типы ИИ ====

==== ИИ Блуждания ====
  * **Класс**: ''Wandering.java''
  * **Поведение**: Перемещается случайно по подземелью
  * **Механика**:
    * Если враг в поле зрения (FOV), переходит в охоту
    * Иначе движется к случайным целям
    * Если получил урон, ищет месть и переходит в охоту
  * **Строка статуса**: ''Mob_StaWanderingStatus'' → «%s блуждает»
  * **Использование**: ИИ по умолчанию для большинства мобов вне боя

==== ИИ Охоты ====
  * **Класс**: ''Hunting.java''
  * **Поведение**: Активная преследование врагов
  * **Механика**:
    * Если враг в FOV и в радиусе атаки, атакует
    * Иначе движется к врагу
    * Если враг потерян, возвращается в блуждание
    * Возвращается к хозяину, если слишком далеко (для питомцев/призванных существ)
  * **Строка статуса**: ''Mob_StaHuntingStatus'' или ''Mob_StaHuntingStatus2''
  * **Использование**: Используется, когда мобы в бою или замечают игрока

==== ИИ Сна ====
  * **Класс**: ''Sleeping.java''
  * **Поведение**: Остается в спящем состоянии до пробуждения
  * **Механика**:
    * Пробуждается только если враг в FOV (с 50% шансом обнаружения)
    * Если получил урон, просыпается и переходит в охоту (с задержкой)
    * Тратит ''Mob.TIME_TO_WAKE_UP'' времени на пробуждение
  * **Строка статуса**: ''Mob_StaSleepingStatus'' → «%s спит»
  * **Использование**: Начальный ИИ для многих подземельных врагов

==== ИИ Пассивное ====
  * **Класс**: ''Passive.java''
  * **Поведение**: Не инициирует бой
  * **Механика**:
    * Никогда не активно ищет врагов
    * Атакует только при получении урона (после поиска мести)
    * Не реагирует на врагов в FOV
  * **Строка статуса**: ''Mob_StaPassiveStatus'' → «%s пассивен»
  * **Использование**: Для нейтральных NPC или оборонительных объектов

==== ИИ Побега ====
  * **Класс**: ''Fleeing.java''
  * **Поведение**: Убегает от врагов
  * **Механика**:
    * Движется в противоположную сторону от позиции врага
    * Непрерывно отслеживает позицию врага во время побега
    * Если получил урон, может искать месть и перейти в охоту
  * **Строка статуса**: ''Mob_StaFleeingStatus'' или ''Mob_StaFleeingStatus2''
  * **Использование**: Используется некоторыми мобами при низком здоровье или ворами

==== Другие типы ИИ ====

==== ИИ Безумства ====
  * **Класс**: ''RunningAmok.java''
  * **Поведение**: Движется случайно, атакуя всё в радиусе досягаемости

==== ИИ Ужаса ====
  * **Класс**: ''Horrified.java''
  * **Поведение**: Испуганное состояние, заставляющее моба бежать

==== ИИ ThiefFleeing ====
  * **Класс**: ''ThiefFleeing.java''
  * **Поведение**: Специализированный ИИ побега для воровских мобов

==== ИИ ControlledAI ====
  * **Класс**: ''ControlledAi.java''
  * **Поведение**: ИИ, которым может управлять игрок (для призванных существ)

==== Реализация ИИ ====
Система ИИ использует паттерн состояние, управляемый в [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/ai/MobAi.java|MobAi]] и [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/actors/mobs/Mob.java|Mob]]:

<code java>
// In Mob.java
public void setState(String state) {
    setState(MobAi.getStateByTag(state));
}

// In Mob.java - переходы состояний ИИ
public void beckon(int cell) {
    // ... код, который может менять состояние ИИ в зависимости от контекста
    if (state.getTag().equals("WANDERING")) {
        // ... может смениться на состояние охоты
    }
}
</code>

==== Триггеры переходов ИИ ====
  * **Урон**: Когда моб получает урон, обычно ищет месть и переходит в ИИ Охоты
  * **Зрение**: Когда моб видит врага во время сна или блуждания, переходит в ИИ Охоты
  * **Здоровье**: Когда здоровье моба падает низко, может перейти в ИИ Побега
  * **Скриптовые события**: Lua-скрипты могут менять состояния ИИ при определённых условиях

==== ИИ в инициализации мобов ====
  * Большинство мобов начинают с ИИ ''Sleeping''
  * Некоторые специальные мобы начинают с ''Wandering'' или другими ИИ
  * ИИ может быть указан в JSON-дескрипторе моба параметром \"aiState\"

==== Строковые ресурсы, связанные с ИИ ====
  * ''Mob_StaWanderingStatus'': «%s блуждает»
  * ''Mob_StaHuntingStatus'': «%s охотится»
  * ''Mob_StaHuntingStatus2'': «%s охотится на %s»
  * ''Mob_StaSleepingStatus'': «%s спит»
  * ''Mob_StaPassiveStatus'': «%s пассивен»
  * ''Mob_StaFleeingStatus'': «%s убегает»
  * ''Mob_StaFleeingStatus2'': «%s убегает от %s»

==== Механики ИИ ====
  * **Обнаружение** — Как враги замечают игрока (зрение, звук и т.д.)
  * **Паттерны движения** — Как враги перемещаются по подземелью
  * **Тактика боя** — Как враги подходят к бою
  * **Поведение при побеге** — Когда и как враги отступают
  * **Переходы состояний** — Как ИИ меняется на основе игровых событий

==== Факторы, влияющие на ИИ ====
  * **Расстояние до игрока** — Насколько далеко враг будет искать
  * **Видимость** — Эффекты освещения и скрытности
  * **Состояние здоровья** — Как враг ведёт себя при травмах
  * **Осведомлённость об окружении** — Взаимодействие с объектами уровня
  * **Обнаружение звука** — Некоторые действия могут привлечь внимание близких врагов

==== Взаимодействие с игроком ====
  * **Линия обзора** — Большинство врагов замечают игрока только если видят его
  * **Шум** — Некоторые действия создают звук, привлекающий врагов
  * **Скрытность** — Некоторые предметы или способности могут снизить шанс обнаружения
  * **Нагнетание** — Некоторые предметы или способности могут манипулировать целью врагов

==== Использование ИИ ====
  * **Кайтинг** — Движение для боя с врагами по одному
  * **Блокирование** — Использование дверных проёмов для боя по одному
  * **Отвлечение** — Использование предметов для отвлечения внимания врагов
  * **Тактика засады** — Использование скрытности и позиционирования
