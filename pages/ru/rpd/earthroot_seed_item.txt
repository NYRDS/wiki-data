====== Семена Земляного Корня ======

{{ rpd:images:earthroot_seed_item.png|Семена Земляного Корня }}

**Семена Земляного Корня** — это [[ru:rpd:seed_item|семена]] от растения Земляной Корень, которые можно посадить или съесть для получения различных эффектов. При поедании они дают защитные способности, накладывая дебафф [[ru:rpd:roots_buff|Корни]] на 25 ходов и бафф [[ru:rpd:barkskin_buff|Короед]], равный 1/4 силы игрока.

==== Специальные свойства ====
  * Можно посадить для выращивания растений Земляной Корень
  * Можно съесть для наложения дебаффа [[ru:rpd:roots_buff|Корни]] (25 ходов) и баффа [[ru:rpd:barkskin_buff|Короед]] (равный 1/4 силы игрока)
  * Часть системы фермерства/алхимии игры
  * Выпадают у [[ru:rpd:earth_elemental_mob|Земляных Элементалей]] с шансом 10%
  * Используются в [[ru:rpd:sprout_spell|Заклинании Рост]] которое случайно сажает одно из различных семян

==== Использование ====
  * **Посадка:** Можно посадить на любую клетку для выращивания растения Земляной Корень, которое дает бафф [[ru:rpd:barkskin_buff|Короед]] при касании
  * **Поедание:** При поедании накладывает [[ru:rpd:roots_buff|Корни]] на 25 ходов (предотвращая движение) и бафф [[ru:rpd:barkskin_buff|Короед]] (броня равная 1/4 силы игрока)
  * **Компонент заклинания:** Используются в [[ru:rpd:sprout_spell|Заклинании Рост]] как часть генерации случайных семян

==== Крафт и алхимия ====
  * **Создание зелий:** Используются для крафта [[ru:rpd:potion_of_paralytic_gas_item|Зелья Парализующего Газа]] в системе алхимии
  * **Предмет Сокровищницы:** Можно найти в комнатах сокровищ (уровни Сокровищницы)

==== Стратегия ====
  * Поедание дает значительную броню, но замораживает на месте на 25 ходов — используйте только в безопасных местах
  * Посадка полезна, когда нужны защитные преимущества в конкретном месте
  * Стоит носить с собой для экстренной защиты в безопасных зонах
