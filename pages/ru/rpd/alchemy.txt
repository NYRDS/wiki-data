====== Алхимия ======

{{ rpd:images:firebloom_seed_item.png|Семена для алхимии }}

Алхимия в Remixed Dungeon — это система варки зелий путем бросания семян в алхимический котел, находящийся в [[ru:rpd:sewers_level|Канализации]]. В отличие от фиксированных рецептов, система случайным образом выбирает зелье на основе брошенных семян.

==== Механика алхимии ====
  * Алхимия выполняется в алхимическом котле (кастрюле) в [[ru:rpd:sewers_level|Уровне Канализации]]
  * Бросьте 3 или более семян в котел, чтобы запустить трансмутацию
  * Котел случайно выбирает одно семя (с весом по количеству) и варит связанное с ним зелье
  * Если у выбранного семени нет класса алхимии, создается случайное зелье из хранилища
  * У каждого типа семени есть свойство **alchemyClass**, определяющее его зелье (например, Солнечник → Зелье исцеления)
  * Семена без класса алхимии (например, Ротбери) дают случайное зелье

==== Соответствие семя → зелье ====
  * **Семя Солнечника** → [[ru:rpd:potion_of_healing_item|Зелье исцеления]]
  * **Семя Огнецвета** → [[ru:rpd:potion_of_liquid_flame_item|Зелье жидкого огня]]
  * **Семя Сновидца** → [[ru:rpd:potion_of_paralytic_gas_item|Зелье парализующего газа]] или [[ru:rpd:potion_of_invisibility_item|Зелье невидимости]] (случайно)
  * **Семя Сновидца** (Dreamweed) → [[ru:rpd:potion_of_mind_vision_item|Зелье ментального зрения]]
  * **Семя Землекорня** / **Семя Увядшего листа** → [[ru:rpd:potion_of_toxic_gas_item|Зелье токсичного газа]]
  * **Семя Ледяника** → [[ru:rpd:potion_of_frost_item|Зелье мороза]]
  * **Семя Ротбери** → [[ru:rpd:potion_of_purity_item|Зелье чистоты]] (нет alchemyClass, случайный выбор из хранилища)
  * **Семя Лунной ласки** → Случайное зелье (alchemyClass не определен)

==== Создание стрел ====
  * Специализированные стрелы можно создать, комбинируя обычные стрелы с зельями:
    * [[ru:rpd:fire_arrow_item|Огненная стрела]] - Из стрел и [[ru:rpd:potion_of_liquid_flame_item|Зелья жидкого огня]]
    * [[ru:rpd:health_arrow_item|Лечебная стрела]] - Из стрел и [[ru:rpd:potion_of_healing_item|Зелья исцеления]]
    * [[ru:rpd:paralysis_arrow_item|Парализующая стрела]] - Из стрел и [[ru:rpd:potion_of_paralytic_gas_item|Зелья парализующего газа]]
    * [[ru:rpd:poison_arrow_item|Отравленная стрела]] - Из стрел и [[ru:rpd:potion_of_toxic_gas_item|Зелья токсичного газа]]

==== Ингредиенты алхимии ====
  * [[ru:rpd:seed_item|Семена]] - Основной ингредиент, получаются от растений
  * Вода - Неявный ингредиент (не предмет) для большинства зелий

==== Стратегия ====
  * Собирайте много семян одного типа, чтобы повысить шанс желаемого зелья
  * Семена Солнечника самые ценные для надежного получения зелий исцеления
  * Бросание смешанных семян дает взвешенно-случайные результаты
  * Алхимический котел в Канализации — единственное фиксированное место; на некоторых уровнях могут быть дополнительные котлы
