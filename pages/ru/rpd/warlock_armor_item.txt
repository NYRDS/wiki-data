====== Броня Чернокнижника ======

{{ rpd:images:warlock_armor_item.png|Броня Чернокнижника }}

Броня Чернокнижника — это классовая броня, получаемая с помощью [[ru:rpd:armor_kit_item|Набора для брони]] на любой обычной броне для подкласса [[ru:rpd:warlock_subclass|Чернокнижник]] класса [[ru:rpd:mage_class|Маг]] в Remixed Dungeon. Функционально идентична [[ru:rpd:battle_mage_armor_item|Броне Боевого мага]], но имеет другой внешний вид.

==== Получение ====
  * Используйте [[ru:rpd:armor_kit_item|Набор для брони]] на любой обычной броне, играя за [[ru:rpd:mage_class|Мага]] с подклассом [[ru:rpd:warlock_subclass|Чернокнижник]]
  * Превращает базовую броню в Броню Чернокнижника с особыми свойствами
  * Примечание: эта броня доступна только для подкласса Чернокнижник

==== Особые свойства ====
  * Наследует все свойства [[ru:rpd:mage_armor_item|Брони Мага]] (способность Взрыв)
  * Способность Взрыв: поджигает и обездвиживает всех видимых врагов на 3 хода
  * Требует достаточное количество очков навыка для активации
  * Эксклюзивна для подкласса [[ru:rpd:warlock_subclass|Чернокнижник]]
