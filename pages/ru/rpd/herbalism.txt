====== Травничество ======

{{ rpd:images:ring_of_herbalism_item.png|Кольцо Травничества }}

**Травничество** в Remixed Dungeon — это игровая механика, связанная с [[ru:rpd:ring_of_herbalism_item|Кольцом Травничества]], которое увеличивает шанс собрать капли росы и семена с вытоптанной травы.

==== Кольцо Травничества ====
Кольцо Травничества — это особое кольцо, улучшающее способность игрока собирать ресурсы из подземелья.

  * **Тип:** Кольцо
  * **Редкость:** Необычное
  * **Эффект:** Увеличивает шанс собрать росу и семена с вытоптанной травы

==== Механика ====
  * При ношении Кольца Травничества, наступление на траву имеет повышенный шанс уронить:
    * [[ru:rpd:dewdrop_item|Капля росы]] — используется для лечения и улучшения Фляги Росы
    * Различные [[ru:rpd:seeds_mechanic|Семена]] — используются для алхимии и крафта
  * Эффект кольца масштабируется с уровнем улучшения
  * Более высокие уровни улучшения дают лучшие шансы на сбор ресурсов

==== Стратегия ====
  * Кольцо Травничества особенно полезно для длинных забегов, где сбор ресурсов становится важным
  * Сочетание этого кольца с осторожным хождением по траве может дать значительные ресурсы со временем
  * Наиболее ценно при сборе конкретных семян для рецептов алхимии

==== Получение ====
  * Можно найти в контейнерах и сундуках подземелья
  * Может быть куплено в магазинах
  * Может выпасть с определённых врагов

==== Связанные предметы ====
  * [[ru:rpd:ring_of_herbalism_item|Кольцо Травничества]] — кольцо, дающее преимущества травничества
  * [[ru:rpd:dewdrop_item|Капля росы]] — один из ресурсов, собираемых через травничество
  * [[ru:rpd:seeds_mechanic|Семена]] — семена растений, собираемые через травничество
  * [[ru:rpd:alchemy_mechanic|Алхимия]] — использует семена, собранные через травничество
