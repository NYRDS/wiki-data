====== Доспех Гладиатора ======

{{ rpd:images:gladiator_armor_item.png|Доспех Гладиатора }}

**Доспех Гладиатора** — это особый классовый доспех для подкласса [[ru:rpd:gladiator_subclass|Гладиатор]] в Remixed Dungeon. Он расширяет [[ru:rpd:warrior_armor_item|Доспех Воина]] и даёт ту же способность «Прыжок».

==== Обзор предмета ====
  * **Тип:** [[ru:rpd:class_armor_item|Классовый доспех]]
  * **Подкласс:** [[ru:rpd:gladiator_subclass|Гладиатор]] (подкласс Воина)
  * **Особый эффект:** Включает способность «Прыжок» (унаследовано от Доспеха Воина)
  * **Использование:** Экипируется как броня для тела
  * **Ограничение:** Может экипироваться только персонажами с подклассом Гладиатор
  * **Идентификация:** Становится идентифицированным при ношении или при просмотре в инвентаре после идентификации

==== Особые механики ====
  * **Способность «Прыжок»:** Позволяет носителю прыгать к выбранной клетке
  * **Эффект оглушения:** Оглушает соседних врагов на 3 хода при приземлении
  * **Стоимость очков навыков:** Требует очков навыков для использования (стоимость = максимальные очки навыков / 3 + 1)
  * **Ограничение подкласса:** Может экипироваться только Гладиатором — попытка экипировать без подкласса вызовет предупреждение
  * **Защита:** Обеспечивает стандартную защиту в дополнение к особым эффектам
  * **Унаследованные свойства:** Наследует все свойства базового класса Доспех Воина

==== Получение ====
  * Используйте [[ru:rpd:armor_kit_item|Набор для брони]] на любом обычном доспехе, играя за подкласс Гладиатор
  * Превращает базовый доспех в Доспех Гладиатора с особыми свойствами
  * Доспех сохраняет все свойства исходного доспеха (защита, зачарование, уровень)
  * Набор для брони находится на уровне Города, выпадает с босса Король

==== Эффект ====
При ношении персонажем с подклассом [[ru:rpd:gladiator_subclass|Гладиатор]] доспех включает особую способность «Прыжок». Эта способность позволяет прыгать к выбранной клетке и оглушать соседних врагов на 3 хода.
