====== Подклассы ======

{{ rpd:images:hero_necromancer_lich.png|Подклассы героя }}

Подклассы — это продвинутые пути специализации, доступные героям в Remixed Dungeon после достижения определенных вех. Каждый игровой класс имеет свою уникальную систему подклассов, предоставляющую особые способности и изменения игрового процесса.

==== Доступные подклассы ====
  * [[ru:rpd:assassin_subclass|Ассасин]] — для [[ru:rpd:rogue_class|Разбойника]], специализация на скрытности и критических ударах
  * [[ru:rpd:battlemage_subclass|Боевой Маг]] — для [[ru:rpd:mage_class|Мага]], сочетание магии с зачарованием оружия
  * [[ru:rpd:berserker_subclass|Берсерк]] — для [[ru:rpd:warrior_class|Воина]], специализация на ярости и уроне
  * [[ru:rpd:gladiator_subclass|Гладиатор]] — для [[ru:rpd:warrior_class|Воина]], акцент на мастерстве владения оружием и комбо-атаках
  * [[ru:rpd:freerunner_subclass|Бегун]] — для [[ru:rpd:rogue_class|Разбойника]], акцент на мобильности и уклонении
  * [[ru:rpd:sniper_subclass|Снайпер]] — для [[ru:rpd:huntress_class|Охотницы]], специализация на дальнем бою
  * [[ru:rpd:warden_subclass|Хранитель]] — для [[ru:rpd:huntress_class|Охотницы]], акцент на природе и деревянном снаряжении
  * [[ru:rpd:lich_subclass|Лич]] — для [[ru:rpd:necromancer_class|Некроманта]], вершина некромантической силы
  * [[ru:rpd:warlock_subclass|Чернокнижник]] — для [[ru:rpd:mage_class|Мага]], специализация на призыве и высасывании жизни
  * [[ru:rpd:scout_subclass|Разведчик]] — для [[ru:rpd:elf_class|Эльфа]], акцент на исследовании и скрытности
  * [[ru:rpd:shaman_subclass|Шаман]] — для [[ru:rpd:elf_class|Эльфа]], акцент на тотемах и стихийной магии
  * [[ru:rpd:witchdoctor_subclass|Знахарь]] — для [[ru:rpd:doctor_class|Доктора]], специализация на болезнях и токсичных эффектах

==== Получение ====
Подклассы обычно получают через:
  * Специальные предметы, найденные в глубоких уровнях подземелья
  * Классовые испытания или задания
  * Специальные взаимодействия с NPC или объектами уровня
  * Уникальные механики для каждого класса

==== Механика ====
  * Подклассы часто дают уникальные способности, изменения характеристик или механики
  * Некоторые подклассы имеют компромиссы (например, [[ru:rpd:lich_subclass|Лич]] получает некромантическую силу, но теряет физическую силу)
  * Подклассы — это постоянный выбор, который значительно меняет игровой процесс
  * Каждый подкласс разработан для предоставления разного игрового опыта
