====== Кора ======

{{ rpd:images:barkskin_buff.png|Кора }}

**Кора** — это полезный статус-эффект в Remixed Dungeon, временно увеличивающий броню персонажа (DR) и делая его более устойчивым к физическому урону.

==== Механика ====
  * **Эффект:** Увеличивает DR (снижение урона) на величину, равную текущему уровню баффа
  * **Длительность:** Уровень баффа снижается на 1 каждый ход; при достижении 0 эффект истекает
  * **Начальный уровень:** Устанавливается источником применения баффа
  * **Бонус DR:** Равен текущему уровню баффа

==== Источники ====
Кору можно получить следующими способами:

  * **[[ru:rpd:nature_armor_spell|Заклинание Природной Брони]]** (заклинание Эльфа) — применяет Кору с начальным уровнем = уровень навыка заклинателя × уровень заклинателя
  * **Замороженный Карпаччо** (еда) — 20% шанс применить Кору с начальным уровнем = макс. ЗД героя / 4
  * **Высокая Трава** (особенность уровня) — применяет Кору с начальным уровнем = макс. ЗД героя / 3 **только для подкласса Страж**
  * **Растение** (взаимодействие) — применяет Кору с начальным уровнем = макс. ЗД героя / 3 **только для подкласса Страж**
  * **Паучье Чувиво** (моб) — имеетKORу среди своих баффов

==== Примечание про Земляной Корень ====
**[[ru:rpd:earthroot_level_object|Земляной Корень]]** применяет **другой бафф** — **Броня Земляного Корня** (ID баффа "Armor"), а не Кору. Броня Земляного Корня поглощает урон в пул поглощения, пока герой остается на той же клетке; перемещение снимает бафф. См. [[ru:rpd:earthroot_level_object|Земляной Корень]] для подробностей.
