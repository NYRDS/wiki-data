====== Ряса Жреца ======

{{ rpd:images:priest_hero.png|Ряса Жреца }}

**Ряса Жреца** (внутреннее название: Priest Armor) — классовая броня для [[ru:rpd:priest_class|Жреца]] в Remixed Pixel Dungeon. Она поддерживает способности исцеления и очищения Жреца.

==== Описание ====
Как и другие классовые доспехи, Ряса Жреца имеет уникальную специальную способность. Однако текущая реализация является заглушкой без запрограммированной способности.

==== Специальная способность ====
В настоящее время Ряса Жреца не имеет реализованной специальной способности:
  * Метод special() возвращает пустую строку
  * Метод doSpecial() пуст и не выполняет никаких действий

==== Примечания по реализации ====
Класс Рясы Жреца служит заглушкой для будущей реализации. Хотя он расширяет ClassArmor, как и другие классовые доспехи, его специальные способности ещё не запрограммированы.

==== Проверка содержимого ====
  * Источник информации: [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/items/common/armor/PriestArmor.java|PriestArmor.java]]
  * Детали реализации: На основе анализа кода PriestArmor.java

==== Ограничение класса ====
Эта броня может эффективно использоваться только классом Жрец. При ношении другими классами она может работать некорректно.
