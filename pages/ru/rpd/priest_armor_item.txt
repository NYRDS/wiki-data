====== Ряса Жреца ======

{{ rpd:images:priest_hero.png|Ряса Жреца }}

**Ряса Жреца** (внутреннее название: Priest Armor) — классовая броня для [[ru:rpd:priest_class|Жреца]] в Remixed Pixel Dungeon. Она поддерживает способности исцеления и очищения Жреца.

==== Описание ====
Ряса Жреца — это классовый доспех, доступный исключительно для класса Жрец. При попытке экипировки другим классом выводится предупреждение. Броня имеет уникальную активную специальную способность «Освящение» (Sanctify), наносящую урон нежити и демонам в радиусе 2 клетки и накладывающую бафф «Благословение» на героя.

==== Специальная способность: Освящение ====
  * **Радиус действия:** 2 клетки
  * **Урон нежити:** 5 + уровень героя
  * **Урон демонам:** половина урона по нежити (минимум 1)
  * **Дополнительный эффект:** Накладывает бафф [[ru:rpd:blessed_buff|Благословение]] (Blessed) на героя на 20 ходов, уровень баффа = 1 + уровень героя / 5
  * **Визуальные эффекты:** Золотые частицы (ShaftParticle.GOLD_FACTORY) на пораженных врагах и на герое
  * **Звук:** Звук повышения уровня (SND_LEVELUP)
  * **Время восстановления:** Один ход (user.doOperate(Actor.TICK))

==== Примечания по реализации ====
Класс реализован в `PriestArmor.java` и расширяет `ClassArmor`. Метод `special()` возвращает строку `"PriestArmor_ACSpecial"` для идентификации способности в интерфейсе. Метод `doSpecial()` содержит полную логику способности. Метод `doEquip()` проверяет класс героя — только `HeroClass.PRIEST` может экипировать эту броню.

==== Ограничение класса ====
Эта броня может эффективно использоваться только классом Жрец. При ношении другими классами она может работать некорректно — попытка экипировки выводит предупреждение `PriestArmor_NotPriest` и возвращает `false`.
