====== Стрела ======

Стрела — базовый класс для всех предметов-стрел в Remixed Dungeon.

==== Описание ====
Стрелы — это предметы-боеприпасы, используемые с луками для дальнобойного боя. Разные типы стрел обеспечивают различные эффекты при выстреле по врагам или использовании в алхимии.

==== Базовые свойства ====
  * **Можно стакать**: Да — стрелы можно складывать в стопки до 99 предметов на слот
  * **Тип**: Боеприпасы для дальнобойного оружия
  * **Использование**: Расходуются при выстреле из лука
  * **Вес**: 1 за единицу

==== Типы стрел ====
  * **Обычные стрелы** — базовые стрелы, наносящие урон
  * **Особые стрелы** — обеспечивают дополнительные эффекты: огонь, яд или паралич
  * **Алхимические стрелы** — используются как ингредиенты в рецептах алхимии

==== Общие механики ====
  * **Крафт**: Стрелы можно создавать через алхимию, используя определённые рецепты
  * **Зачарования**: Некоторые стрелы можно зачаровывать через алхимию
  * **Совместимость**: Рассчитаны на работу со всеми типами луков
  * **Урон**: Базовый урон обычно составляет 1-4 единицы
