====== Луки и Стрелы ======

{{ rpd:images:wooden_bow_item.png|Деревянный лук }}

В Remixed Pixel Dungeon есть новый тип оружия — луки. Любой класс может использовать лук, но только [[ru:rpd:elf_class|эльф]] наносит полный урон на близком расстоянии. Стрелы необходимы для стрельбы.

==== Как работают луки ====
  * Луки — дальнобойное оружие, требующее стрел
  * При экипировке стрелами лук позволяет атаковать врагов на расстоянии
  * Только эльфы наносят значительный урон стрелами в упор
  * Другие классы наносят очень мало урона при стрельбе в упор

===== Список луков =====
  * [[ru:rpd:wooden_bow_item|Деревянный лук]] — простейший лук. Требует 9 силы.
  * [[ru:rpd:compound_bow_item|Блочный лук]] — улучшенный лук. Требует 11 силы.
  * [[ru:rpd:ruby_bow_item|Рубиновый лук]] — самый мощный лук. Требует 13 силы.

===== Список стрел =====
  * [[ru:rpd:common_arrow_item|Обычная стрела]] — базовый урон 2–5.
  * [[ru:rpd:fire_arrow_item|Огненная стрела]] — поджигает врага с 25% шансом.
  * [[ru:rpd:frost_arrow_item|Морозная стрела]] — замедляет врага с 25% шансом.
  * [[ru:rpd:poison_arrow_item|Отравленная стрела]] — отравляет врага с 25% шансом.
  * [[ru:rpd:paralysis_arrow_item|Парализующая стрела]] — парализует с 25% шансом.
  * [[ru:rpd:health_arrow_item|Стрела здоровья]] — лечит героя с 25% шансом.
  * [[ru:rpd:amok_arrow_item|Стрела безумия]] — вызывает безумие с 25% шансом.

==== Получение особых стрел ====
  * [[ru:rpd:potion_of_liquid_flame_item|Зелье жидкого пламени]] + стрела → [[ru:rpd:fire_arrow_item|Огненная стрела]]
  * [[ru:rpd:potion_of_frost_item|Зелье мороза]] + стрела → [[ru:rpd:frost_arrow_item|Морозная стрела]]
  * [[ru:rpd:potion_of_toxic_gas_item|Зелье ядовитого газа]] + стрела → [[ru:rpd:poison_arrow_item|Отравленная стрела]]
  * [[ru:rpd:potion_of_paralytic_gas_item|Зелье парализующего газа]] + стрела → [[ru:rpd:paralysis_arrow_item|Парализующая стрела]]
  * [[ru:rpd:potion_of_healing_item|Зелье исцеления]] + стрела → [[ru:rpd:health_arrow_item|Стрела здоровья]]
  * [[ru:rpd:potion_of_strength_item|Зелье силы]] + стрела → [[ru:rpd:amok_arrow_item|Стрела безумия]]
