====== Грустномох (Объект Уровня) ======

{{ rpd:images:sorrowmoss_level_object.png|Грустномох }}

**Грустномох** — это опасное растение, встречающееся в подземелье, которое выделяет смертельный токсин. При прямом касании оно наносит урон, но его семена можно собрать и использовать в алхимии или создании зелий.

==== Эффекты ====
  * Наносит урон персонажам, касающимся его напрямую
  * Дает семена Грустномоха при сборе
  * Семена можно использовать для создания зелий или посадки

==== Механика ====
  * Объекты Грустномоха можно найти растущими в подземелье
  * Их также можно вырастить, посадив [[ru:rpd:sorrowmoss_seed_item|Семена Грустномоха]]
  * Прямой контакт наносит урон персонажу
  * Семена можно собрать безопасно с правильной техникой

==== Использование ====
  * Собирайте семена, сражаясь с объектом или аккуратно проходя мимо
  * Используйте 3 или более семян в алхимическом котле для потенциального создания Зелья Токсичного Газа
  * Семена также можно сажать на плодородной почве

==== Стратегия ====
  * Подходите с осторожностью из-за токсичной природы
  * Рассмотрите использование дальнобойных атак для безопасного сбора семян
  * Ценны для алхимии благодаря созданию зелья токсичного газа
  * Объекты Грустномоха опасны, но дают ценные семена
