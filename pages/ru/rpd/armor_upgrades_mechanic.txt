====== Улучшение Брони ======

Улучшение брони в Remixed Dungeon повышает защитные возможности с помощью различных механизмов.

==== Методы Улучшения ====

===== Свиток Улучшения =====
[[en:rpd:scroll_of_upgrade_item|Свиток Улучшения]] можно использовать на любой части брони для:
  * Увеличения уровня брони на +1
  * Снятия проклятий с брони
  * Возможного добавления или удаления глифа (случайный шанс при отсутствии глифа)
  * Увеличения рейтинга защиты: DR = уровень × 2 + уровень × уровень (+ уровень с глифом)

**Важно:** При улучшении брони с глифом существует вероятность потери глифа, если текущий уровень брони низкий. Формула: если Random.Int(level()) > 0, глиф удаляется.

===== Комплект Брони =====
[[en:rpd:armor_kit_item|Комплект Брони]] — особый предмет, который:
  * Превращает обычную броню в классовую броню
  * Не может быть улучшен сам (isUpgradable() возвращает false)
  * Уже идентифицирован при находке
  * Выпадает с босса [[en:rpd:king_mob|King]]
  * При использовании предлагает выбрать броню для трансформации
  * Создаёт экземпляр ClassArmor, специфичный для класса героя

==== Система Классовой Брони ====
Классовая броня — особый тип брони, уникальный для каждого класса героя:
  * **Warrior**: Cuirass of the Warrior
  * **Mage**: Robe of the Mage
  * **Rogue**: Garb of the Rogue
  * **Huntress**: Suit of the Huntress
  * **Elf**: Elven Armor
  * **Necromancer**: Necromancer's Robes

Классовая броня обеспечивает улучшенные защитные возможности и может иметь особые свойства, уникальные для класса героя.

==== Расчёт Защиты Брони ====
Эффективный рейтинг защиты (DR) брони рассчитывается как:
  * **Базовый DR**: уровень × 2
  * **За уровень**: +уровень за уровень улучшения
  * **С глифом**: +уровень дополнительного DR
  * **Формула**: effectiveDr() = уровень × 2 + level() × уровень + (glyph != null ? уровень : 0)

Например, броня уровня 3 на +2 с глифом имеет: DR = 3×2 + 2×3 + 3 = 15

==== Взаимодействие с Глифами ====
Броня может иметь глифы (особые зачарования), которые:
  * Обеспечивают дополнительные защитные эффекты
  * Могут быть потеряны при улучшении, если Random.Int(level()) > 0
  * Гарантированно сохраняются при инскрипции во время улучшения
  * Добавляют +уровень к рейтингу защиты брони

==== Требования к Силе ====
Требования к силе для брони зависят от уровня:
  * **Формула**: typicalSTR() = 7 + уровень × 2
  * **Примеры**: Уровень 1 = 9 STR, Уровень 2 = 11 STR, Уровень 3 = 13 STR
  * Ношение брони без достаточной силы влечёт штрафы

==== Механика Идентификации ====
  * Новая броня начинается неидентифицированной
  * Требуется 10 полученных ударов в броне для идентификации
  * После идентификации показывает уровень и характеристики брони
  * Значки присуждаются при получении уровня предмета

==== Стратегия ====
  * Используйте Свиток Улучшения на броне высокого уровня для максимального увеличения DR
  * Учитывайте, что глифы могут быть потеряны при улучшении
  * Сохраните Комплект Брони для лучшей найденной брони
  * Учитывайте требования к силе при планировании улучшений брони
  * Классовая броня обычно превосходит обычную броню того же уровня
