====== Разбойничий Комбинезон (Rogue Armor) ======

{{ rpd:images:rogue_armor_item.png|Разбойничий Комбинезон }}

**Разбойничий Комбинезон** — это классовая броня для класса [[ru:rpd:rogue_class|Разбойник]] в Remixed Dungeon. Она обладает специальной способностью **«Дымовая Шашка»**.

==== Характеристики ====
  * **Тип:** Классовая броня
  * **Необходимый класс:** [[ru:rpd:rogue_class|Разбойник]]
  * **Необходимый подкласс:** Требуется выполнить испытание мастерства (например, [[ru:rpd:freerunner_subclass|Вольный Бегун]])
  * **Класс брони:** Средний
  * **Прочность:** Средняя
  * **Бонус к скрытности:** Высокий

==== Способности ====
  * **Дымовая Шашка:** Создаёт дымку, позволяющую разбойнику стать невидимым на короткое время и телепортироваться в любую видимую точку
  * **Улучшенная скрытность:** Повышенные способности к стелсу по сравнению с обычной броней
  * **Мобильность:** Позволяет быстро убегать и менять позицию во время боя

==== Описание ====
Разбойничий Комбинезон создан для разбойников, овладевших навыками скрытности и мобильности. Его способность «Дымовая Шашка» предоставляет исключительные возможности для побега и тактического позиционирования, делая его идеальным для тактики «удар и беги».

==== Получение ====
Чтобы получить Разбойничий Комбинезон:

  1. Найдите [[ru:rpd:armor_kit_item|Набор для Брони]] у босса [[ru:rpd:king_mob|Король]] в зале уровня
  2. Улучшите обычный предмет брони, используя Набор для Брони
  3. При запросе выберите специализацию «Разбойничий Комбинезон»

==== Особые эффекты ====
  * **Невидимость:** Временно делает разбойника невидимым при использовании Дымовой Шашки
  * **Телепортация:** Позволяет разбойнику телепортироваться в любую видимую точку во время невидимости
  * **Тактический побег:** Даёт несколько вариантов выхода из сложных ситуаций
