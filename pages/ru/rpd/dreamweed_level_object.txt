====== Дурман-трава (Объект Уровня) ======

{{ rpd:images:dreamweed_level_object.png|Дурман-трава }}

Объект уровня Дурман-трава выпускает облако газа сбивчивости при касании. Когда персонаж или враг наступает на клетку, содержащую объект уровня Дурман-трава, создается блоб ConfusionGas в этой позиции, затрагивающий близлежащих существ.

==== Эффекты ====
  * Создает облако газа сбивчивости в позиции касания (радиус зависит от глубины подземелья)
  * Сбивчивость заставляет пораженных существ двигаться случайно и действовать непредсказуемо
  * Эффект сбивчивости длится в зависимости от глубины подземелья (300 + 20 * глубина)
  * Объект уровня исчезает после касания

==== Механика ====
  * Объекты Дурман-травы можно найти растущими в подземелье
  * Эффект газа сбивчивости полезен для разрушения формаций врагов
  * Сбившиеся с толку существа двигаются случайно и могут атаковать союзников
  * Семена Дурмана можно сажать для выращивания новых объектов Дурман-трава
  * При поедании семена Дурмана накладывают баффы Головокружения и Зрения Разума

==== Стратегия ====
  * Объекты Дурман-травы полезны для разрушения групп врагов
  * Можно использовать для создания хаоса и побега из опасных ситуаций
  * Эффективны против врагов, полагающихся на координированные атаки
  * Рассмотрите посадку семян Дурмана для создания тактических зон сбивчивости
