====== Крафт ======

Крафт относится к различным методам создания новых предметов в Remixed Dungeon, в основном через систему **[[ru:rpd:alchemy|Алхимия]]**.

==== Алхимия на основе крафта ====
  * **Алхимические котлы**: Стационарные объекты, найденные на уровнях подземелья, позволяющие трансформировать предметы
  * **Рецепты**: Конкретные комбинации предметов, создающие новые предметы
  * **Увлажнение**: Использование зелий на стрелах для создания специального снаряжения

==== Рецепты алхимии ====
  * **Зелье + Семя** → Другое зелье
  * **Зелье + Стрела** → Специальная стрела (через **[[ru:rpd:moisten|увлажнение]]**)
  * **Семя + Еда** → Зелье
  * **Свиток + Свиток** → Другой свиток
  * **Предмет + Золото** → Свиток (случайного типа)

==== Стратегия ====
  * Превращайте ненужные предметы в нужные для оптимизации инвентаря
  * Создавайте специализированные боеприпасы для конкретных ситуаций
  * Генерируйте припасы, когда ресурсы на исходе
  * Используйте крафт для безопасного устранения проклятых предметов

==== Расположение крафтов ====
  * **Алхимические котлы**: Рассыпаны по уровням подземелья
  * **Особые зоны**: Некоторые уровни имеют множественные возможности для крафта
  * **Лавки**: Иногда содержат алхимические котлы для покупки

==== Ограничения ====
  * Требует конкретных комбинаций предметов
  * Нужен доступ к алхимическим котлам или другим объектам крафта
  * Некоторые рецепты имеют случайные результаты
  * Крафт не может создавать все типы предметов
