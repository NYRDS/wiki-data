====== Броня Снайпера ======

{{ rpd:images:sniper_armor_item.png|Броня Снайпера }}

==== Описание ====
**Броня Снайпера** — это специальная [[ru:rpd:armor_class|броня]], которую можно получить только с помощью [[ru:rpd:armor_kit_item|Набора для брони]] на любой обычной броне, играя за подкласс [[ru:rpd:sniper_subclass|Снайпер]]. Она предоставляет уникальные преимущества, дополняющие стиль дальнего боя Снайпера.

==== Характеристики ====
  * **Тип брони**: Тип брони Охотницы
  * **Особое свойство**: При ношении подклассом Снайпер даёт повышенную точность в дальнем бою
  * **Требования**: Может быть создана только подклассом Снайпер с помощью Набора для брони
  * **Прочность**: Стандартная прочность брони

==== Особенности ====
  * **Дальняя точность**: Даёт бонус к точности дальних атак
  * **Скрытность**: Может предоставлять дополнительные преимущества скрытности при бесшумном движении
  * **Синергия с Снайпером**: Работает в связке со способностями подкласса Снайпер

==== Получение ====
  * **Способ**: Используйте [[ru:rpd:armor_kit_item|Набор для брони]] на любой обычной броне, играя за подкласс Снайпер
  * **Место**: Набор для брони находится в залах Демонов (Demon Halls), выпадает с босса Короля
  * **Предварительные условия**: Необходимо играть за подкласс Снайпер, чтобы создать эту броню

==== Стратегия ====
  * Сочетайте с естественными дальними способностями Снайпера для максимальной эффективности
  * Используйте бонусы брони к точности при стрельбе из дальнего оружия
  * Применяйте в связке с другими предметами и способностями, специфичными для Снайпера
