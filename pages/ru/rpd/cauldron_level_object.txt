====== Котел (Алхимия) ======

{{ rpd:images:pot_level_object.png|Алхимический котел }}

**Алхимический котел** (также называемый Котлом в описаниях игры) — это интерактивный объект уровня в Remixed Dungeon, позволяющий готовить зелья, бросая в него семена.

==== Описание ====
Алхимический котел — это кипящий котел, который можно найти на некоторых уровнях подземелья. Игрок может взаимодействовать с ним, выбирая семя из инвентаря и бросая в котел, после чего будет сварено зелье по рецепту алхимии. Котел отображается как декоративный объект с визуальным эффектом кипения.

==== Механика ====
  * **Взаимодействие:** Подойдите к котлу и выберите «Взаимодействовать», чтобы открыть меню выбора семени
  * **Вход:** Требуется семя из инвентаря, которое бросается в котел
  * **Выход:** Производит зелье в зависимости от использованного семени и текущих рецептов алхимии
  * **Визуальный эффект:** Отображает эффект кипящего котла при активности
  * **Местоположение:** Встречается на различных уровнях подземелья, особенно в тематических зонах алхимии

==== Процесс приготовления ====
1. Найдите **Алхимический котел** в подземелье
2. Подойдите и взаимодействуйте
3. Выберите семя из инвентаря для броска
4. Котел сварит и произведет зелье на основе рецепта

==== Распространенные рецепты ====
  * **Семя Солнечной травы** → Зелье лечения
  * **Семя Огнецвета** → Зелье жидкого пламени
  * **Семя Ледяного капюшона** → Зелье мороза
  * **Семя Печальника** → Зелье токсичного газа
  * **Семя Снодействия** → Зелье невидимости
  * **Семя Корня земли** → Зелье силы (на глубине 5+)

*Примечание: Рецепты можно расширить через Lua-скрипты в `scripts/alchemy_recipes.lua`*

==== Стратегия ====
  * **Управление ресурсами:** Сохраняйте семена для наиболее нужных зелий
  * **Знание рецептов:** Изучайте распространенные рецепты, чтобы не тратить семена впустую
  * **Учет глубины:** Некоторые рецепты (например, зелье силы) открываются только на большей глубине
  * **Экстренное лечение:** Семена Солнечной травы ценны для создания зелий лечения
