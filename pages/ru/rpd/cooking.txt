====== Готовка ======

**Готовка** — это игровая механика в Remixed Dungeon, позволяющая игрокам преобразовывать определённые предметы с помощью [[ru:rpd:cauldron_level_object|Котел]].

==== Обзор ====
Готовка выполняется в котле, который можно найти на некоторых уровнях подземелья. Игроки могут использовать котел для безопасной обработки потенциально опасных предметов в полезные.

==== Предметы для готовки ====
Основное использование готовки — превращение [[ru:rpd:mystery_meat_item|Мяса невиданного зверя]] в [[ru:rpd:chargrilled_meat_item|Жареное мясо]], которое безопасно в употреблении, в отличие от мяса невиданного зверя со его случайными эффектами.

==== Процесс ====
1. Найдите [[ru:rpd:cauldron_level_object|Котел]] в подземелье
2. Подойдите к котлу с предметом для готовки
3. Выберите опцию готовки в меню
4. Предмет будет преобразован согласно рецептам готовки

==== Преимущества ====
  * **Безопасность:** Превращает опасные предметы (например, мясо невиданного зверя) в безопасные аналоги
  * **Эффективность ресурсов:** Позволяет игрокам использовать предметы, которые иначе могли бы быть рискованны для потребления
  * **Управление инвентарём:** Помогает управлять предметами еды и предотвращать негативные эффекты

  * Описание процесса: На основе анализа кода реализации готовки
