====== Шаман ======
{{ rpd:images:elf_shaman_hero.png|Шаман }}

**Шаман** — это подкласс Эльфа в Remixed Dungeon.

===== Описание =====
Эльфийские //Шаманы// могут использовать жезлы как оружие ближнего боя. Успешные удары имеют шанс активировать силу жезла на цели без расхода заряда.

===== Разблокировка =====
Подкласс Шаман можно разблокировать, используя [[ru:rpd:tome_of_mastery_item|Том Мастерства]] после победы над вторым боссом (Тенгу).

===== Специальные механики =====
  * Эльфийские _Шаманы_ могут использовать [[ru:rpd:wands|жезлы]] как [[ru:rpd:melee_weapons|оружие ближнего боя]]
  * При атаке с жезлом, экипированным как основное оружие, есть 25% шанс (реализовано как Random.Int(4) == 0) зажечь цель силой жезла без расхода заряда
  * Эта способность реализована в методе ''attackProc'' класса ''HeroSubClass.java'' (строки 144-153)
  * Жезл должен быть экипирован как основное оружие (активное оружие) для работы этой механики
  * Жезл должен иметь доступные заряды и метод ''affectTarget()'' должен вернуть true
  * +1 бонус к росе для усиленного [[ru:rpd:mana_mechanic|восстановления маны]]
  * **mr: namespace:** См. [[mr:shaman_subclass]] для машиночитаемых данных

===== Технические детали =====
  * **Реализация:** Специальные механики Шамана реализованы в методе ''attackProc'' класса ''HeroSubClass.java'' (строки 144-153)
  * **Активация жезла:** Когда Шаман атакует с жезлом, экипированным как активное оружие, есть 25% шанс зажечь врага эффектом жезла без расхода заряда
  * **Ссылка на код:** Конкретная реализация проверяет, является ли основное оружие жезлом, и если ''affectTarget()'' возвращает true и ''Random.Int(4) == 0'', то вызывается ''zapCell()'' для зажигания врага без расхода заряда

===== Специальная броня =====
Использование [[ru:rpd:armor_kit_item|Набора для брони]] на любой броне превратит её в [[ru:rpd:shaman_armor_item|Броню Шамана]], специально разработанную для этого подкласса.

===== Преимущества =====
  * Может использовать [[ru:rpd:wands|жезлы]] как [[ru:rpd:melee_weapons|оружие ближнего боя]]
  * 25% шанс активировать силы жезла без расхода зарядов
  * Универсальные варианты оружия, сочетающие [[ru:rpd:ranged_weapons|дальнее]] и [[ru:rpd:melee_combat|ближнее]]
  * Сохраняет заряды жезлов при активации силы
  * Хорошо работает со всеми [[ru:rpd:wands|типами жезлов]]
  * +1 бонус к росе для усиленного [[ru:rpd:mana_mechanic|восстановления маны]]

===== Недостатки =====
  * Шанс активации не гарантирован (25% шанс)
  * Урон жезла как [[ru:rpd:melee_mechanic|оружия ближнего боя]] может быть ниже, чем у специализированного оружия

===== Проверка данных =====
  * Источник информации: Java Enum ''com.watabou.pixeldungeon.actors.hero.HeroSubClass.SHAMAN''
  * Проверка механик: Бонус атаки реализован в методе ''attackProc'' класса ''HeroSubClass.java'', с 25% шансом зажечь врага
  * Описание эффектов: Основано на строковых ресурсах из values/strings_all.xml (\"HeroSubClass_DescShaman\")
  * Проверка имени: Подтверждена из строковых ресурсов (\"HeroSubClass_NameShaman\")
  * Дополнительные механики: Бонус к росе проверен в методе ''dewBonus'' класса ''HeroSubClass.java''
