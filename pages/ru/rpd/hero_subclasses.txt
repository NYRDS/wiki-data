====== Подклассы героя ======

Подклассы героя — это продвинутые пути специализации, доступные классам героев в Remixed Dungeon.

==== Описание ====
Подклассы героя представляют собой пути мастерства, которые становятся доступны после выполнения конкретных достижений с определёнными классами героев. Они предоставляют дополнительные специальные способности и другие стили игры для продвинутых игроков.

==== Доступные подклассы ====
  * **Подклассы Воина**:
    * [[ru:rpd:gladiator_subclass|Гладиатор]] — Для класса Воин, фокусируется на мастерстве владения оружием
    * [[ru:rpd:berserker_subclass|Берсерк]] — Для класса Воин, фокусируется на бою при низком здоровье
  * **Подклассы Мага**:
    * [[ru:rpd:battlemage_subclass|Боевой Маг]] — Для класса Маг, сочетает боевую магию и заклинания
    * [[ru:rpd:warlock_subclass|Чёрнокнижник]] — Для класса Маг, фокусируется на магии выкачивания жизни
  * **Подклассы Разбойника**:
    * [[ru:rpd:freeranner_subclass|Вольный Бегун]] — Для класса Разбойник, усиленная скорость и скрытность
    * [[ru:rpd:assassin_subclass|Убийца]] — Для класса Разбойник, фокусируется на нанесении высокого урона
  * **Подклассы Эльфа**:
    * [[ru:rpd:shaman_subclass|Шаман]] — Для класса Эльф, специализируется на элементальной магии
    * [[ru:rpd:scout_subclass|Разведчик]] — Для класса Эльф, фокусируется на дальнем бою и разведке
  * **Подклассы Некроманта**:
    * [[ru:rpd:lich_subclass|Лич]] — Для класса Некромант, усиленные некромантические силы

==== Механика подклассов ====
  * **Разблокировка**: Подклассы разблокируются победой над специфическими боссами с соответствующим классом
  * **Специальные способности**: Каждый подкласс дарует уникальные активные способности
  * **Изменения экипировки**: Некоторые подклассы предоставляют уникальную экипировку или предметы
  * **Изменения стиля игры**: Каждый подкласс меняет то, как играет класс

==== Требования для разблокировки ====
  * **Гладиатор/Берсерк**: Победа над Тенгу playing за Воина
  * **Боевой Маг/Чёрнокнижник**: Победа над Тенгу playing за Мага
  * **Вольный Бегун/Убийца**: Победа над Тенгу playing за Разбойника
  * **Шаман/Разведчик**: Победа над Тенгу playing за Эльфа
  * **Лич**: Победа над Йог-Дзева playing за Некроманта
