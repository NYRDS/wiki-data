====== Вещи ======

**Вещи** (Belongings) — это система инвентаря и слотов экипировки героя в Remixed Dungeon. Она включает в себя все предметы, переносимые героем, и их экипировку.

==== Система инвентаря ====
Система инвентаря в Remixed Dungeon состоит из нескольких отдельных разделов:

  * **Основной инвентарь**: 22 ячейки для переноса предметов
  * **Слоты экипировки**: Специальные слоты для надеваемых предметов
  * **Быстрые слоты**: 4 слота для предметов, к которым можно быстро получить доступ в бою

==== Слоты экипировки ====
  * **Оружие**: Основное оружие в правой руке (или двуручное оружие)
  * **Левая рука**: Вторичное оружие/щит (левая рука)
  * **Броня**: Нательная броня
  * **Кольца**: Два слота для колец (левая и правая рука)
  * **Амулет**: Слот для Амулета Йендора
  * **Артефакт**: Слот для специального артефакта

==== Управление инвентарём ====
  * **Вместимость**: Ограничена 22 предметами в основном инвентаре
  * **Сумки**: Специальные предметы вроде [[ru:rpd:potion_belt_item|Пояса для зелий]], [[ru:rpd:scroll_holster_item|Кожуха для свитков]] и [[ru:rpd:seed_pouch_item|Мешочка для семян]] расширяют хранение для определённых типов предметов
  * **Быстрые слоты**: Позволяют быстро получать доступ к часто используемым предметам в бою
  * **Стакабельность**: Некоторые предметы стакаются (зелья, свитки, боеприпасы и т.д.)

==== Эффекты экипировки ====
  * **Активные бонусы**: Надетое оружие даёт постоянные преимущества
  * **Пассивные эффекты**: Некоторые предметы имеют пассивные эффекты, просто находясь в инвентаре
  * **Ограничения**: Некоторые предметы требуют определённых характеристик (например, силу для тяжёлой брони) для эффективного использования
