====== Броня Спринтера ======

Броня Спринтера — это специальная броня подкласса, получаемая при использовании [[ru:rpd:armor_kit_item|Набора для брони]] на любой обычной броне для подкласса Спринтер в Remixed Dungeon.

==== Получение ====
  * Используйте [[ru:rpd:armor_kit_item|Набор для брони]] на любой обычной броне, играя за Разбойника с подклассом Спринтер
  * [[ru:rpd:armor_kit_item|Набор для брони]] можно получить, победив босса Короля в Городе
  * Превращает базовую броню в Броню Спринтера с особыми свойствами

==== Особые свойства ====
  * Наследует все свойства [[ru:rpd:rogue_armor_item|Брони Разбойника]] (способность Smoke Bomb)
  * Доступна только для подкласса Спринтер — нельзя надеть, если не выбран этот подкласс
  * Сохраняет защиту (DR) и требование силы (STR) исходной брони
  * Не может быть улучшена дальше

==== Применение ====
  * Необходимая броня для максимальной эффективности подкласса Спринтер
  * Следует создать как можно скорее после выбора подкласса Спринтер

==== Способность: Smoke Bomb ====
  * Позволяет создать дымовую бомбу в указанном месте в поле зрения
  * Требует достаточного количества очков навыка (1/3 от максимума + 1)
  * Можно использовать для побега или смены позиции

==== Примечания ====
  * Часть системы подклассов в Remixed Dungeon
  * Броня подклассов отражает уникальную природу каждого подкласса
  * Нельзя носить персонажам, не разблокировавшим соответствующий подкласс
