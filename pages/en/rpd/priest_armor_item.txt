====== Priest Vestments ======

{{ rpd:images:priest_hero.png|Priest Vestments }}

The **Priest Vestments** (internal name: Priest Armor) is the class-specific armor for the [[en:rpd:priest_class|Priest]] class in Remixed Pixel Dungeon. It's designed to support the Priest's healing and purification abilities.

==== Description ====
The Priest Vestments is a class armor available exclusively to the Priest class. Attempting to equip it with other classes shows a warning. The armor has a unique active special ability "Sanctify" that damages undead and demons within a 2-tile radius and applies the "Blessed" buff to the hero.

==== Special Ability: Sanctify ====
  * **Radius:** 2 tiles
  * **Damage to undead:** 5 + hero level
  * **Damage to demons:** Half of undead damage (minimum 1)
  * **Additional effect:** Applies [[en:rpd:blessed_buff|Blessed]] buff to hero for 20 turns, buff level = 1 + hero level / 5
  * **Visual effects:** Gold particles (ShaftParticle.GOLD_FACTORY) on affected enemies and hero
  * **Sound:** Level-up sound (SND_LEVELUP)
  * **Cooldown:** One turn (user.doOperate(Actor.TICK))

==== Implementation Notes ====
The class is implemented in `PriestArmor.java` and extends `ClassArmor`. The `special()` method returns `"PriestArmor_ACSpecial"` to identify the ability in the UI. The `doSpecial()` method contains the full ability logic. The `doEquip()` method checks the hero class — only `HeroClass.PRIEST` can equip this armor.

==== Class Restriction ====
This armor can only be effectively used by the Priest class. If worn by other classes, it may not function properly — attempting to equip shows the `PriestArmor_NotPriest` warning and returns `false`.
