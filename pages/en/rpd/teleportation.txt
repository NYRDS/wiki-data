====== Teleportation ======

Teleportation is a mechanic that instantly moves a character to a random location on the current dungeon level.

==== Description ====
Teleportation is used by various items, abilities, and level objects in Remixed Dungeon. It moves the target to a random valid tile on the same level, and does not allow transition between dungeon levels.

==== Effects ====
  * Instant movement to a random location
  * Does not work on boss levels
  * Does not allow changing levels
