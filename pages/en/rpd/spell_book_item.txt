====== Spell Book ======

{{ rpd:images:spell_book_item.png|Spell Book }}

==== Description ====
The **Spell Book** is an artifact item in Remixed Dungeon that contains a single spell. When read, it casts the stored spell, allowing heroes to use magic regardless of their class affinity. It serves as a versatile tool for accessing spells that a hero might not naturally be able to learn or cast.

==== Properties ====
  * **Type**: Artifact (extends Artifact class)
  * **Sprite**: `items/books.png` (index 3) → {{ rpd:images:spell_book_item.png|Spell Book }}
  * **Price**: 500 gold
  * **Bag**: Scroll Holder (ScrollHolder)
  * **Default Action**: Read (when equipped)
  * **Stackable**: No (artifact)
  * **Identified**: Shows stored spell name and description
  * **Burnable**: No (burn() returns null)

==== Functionality ====
  * **Spell Storage**: Holds **one spell** at a time (set via `spell(String spellName)`)
  * **Spell Casting**: When read (AC_READ), casts the stored spell via `UseSpell` action
  * **Spell Access**: Allows any hero to cast the contained spell, bypassing class affinity restrictions
  * **Identification**: When identified, name shows as "Spell Book (SpellName)" and description shows the spell's full info

==== Usage ====
  1. **Equip** the Spell Book
  2. **Read** it (default action when equipped) to cast the contained spell
  3. The spell effect applies based on the stored spell's mechanics
  4. The Spell Book is **not consumed** when used - it retains the spell

==== Spell Categories ====
The Spell Book can contain any spell from the game's spell system:
  * **[[en:rpd:combat_mechanic|Combat Spells]]**: Direct damage and battle utility (e.g., Smash, Die Hard)
  * **Utility Spells**: Movement, escape, environmental interaction (e.g., Magic Torch, Blink)
  * **Support Spells**: Healing and buffing (e.g., Heal, Order)
  * **Elemental Spells**: Fire, ice, nature (e.g., Ignite, Root)
  * **Necromancy Spells**: Undead and death-related (e.g., Raise Dead, Exhumation)
  * **Rogue Spells**: Stealth and agility (e.g., Backstab, Haste)
  * **Witchcraft Spells**: Magic manipulation (e.g., Lightning Bolt, Roar)
  * **Huntress/Elf/Priest/PlagueDoctor Spells**: Class-specific affinities

==== Strategy ====
  * **Versatility**: Any class can use any spell via Spell Book
  * **Resource Management**: No mana cost to cast from Spell Book (uses the item's action instead)
  * **Situational Spells**: Carry utility spells (Town Portal, Magic Torch) for emergencies
  * **Boss Fights**: Store high-damage or control spells for difficult encounters
  * **Identification**: Identify to see which spell it contains before committing inventory space
