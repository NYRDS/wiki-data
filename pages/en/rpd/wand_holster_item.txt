====== Wand Holster ======

{{ rpd:images:wand_holster_item.png|Wand Holster }}

The **Wand Holster** is a bag item that allows compact storage of wands.

==== Description ====
A slim leather holder made from exotic animal leather. It provides convenient storage for magical wands.

==== Properties ====
  * **Type**: Bag / Container
  * **Capacity**: Holds up to a configurable number of wands
  * **Price**: 50 gold
  * **Stackable**: No

==== Acquisition ====
  * Found in dungeon chests
  * Available in shops

==== Mechanics ====
  * Extends the Bag class for inventory management
  * Specifically designed to hold wands
  * Capacity is defined by configuration
