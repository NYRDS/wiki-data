====== Sociologist ======

{{ rpd:images:sociologist_npc_mob.png|Sociologist }}

**⚠️ Note:** This NPC has been removed from the game (deleted entirely as a "dead promo stub" per MobFactory.java). The Java class `SociologistNPC.java` no longer exists. This page is kept for historical reference only.

==== Description ====
The **Sociologist** was an NPC character in Remixed Dungeon who asked if the player wants to participate in a survey. This character was part of a gameplay feature that allowed players to access survey content.

==== Location ====
  * Was found randomly in the dungeon levels (before removal)

==== Interactions ====
  * The NPC presented a dialogue asking the player if they'd like to participate in a survey
  * If the player agreed, requested internet permission to download survey content
  * If the player refused, the NPC left the player alone

==== Implementation (Historical) ====
  * **Former Java Class:** SociologistNPC.java (deleted)
  * **Base Class:** ImmortalNPC
  * **Behavior:** Implemented DownloadStateListener.IDownloadComplete and InterstitialPoint interfaces for handling survey downloads from GitHub
