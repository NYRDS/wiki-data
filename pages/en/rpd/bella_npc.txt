====== Bella ======

{{ rpd:images:bellanpc_sprite.png|Bella }}

**⚠️ Note:** This NPC has been removed from the game. The Java class `BellaNPC.java` no longer exists and no JSON/Lua implementation has been found. The MobFactory.java comment states "BellaNPC/FortuneTellerNPC/NecromancerNPC kinds are data now" but no BellaNPC.json file exists. This page is kept for historical reference.

==== Description ====
**Bella** was an NPC encountered at the end of the game in Remixed Pixel Dungeon and served as one of the possible endings.

==== Interactions ====
  * When encountering Bella, she would tell you she bears no interest in such plebs as yourself
  * **Note**: String resources indicate an interaction was intended for when the player has the Amulet of Yendor, but this functionality was not implemented in the code.

==== Implementation (Historical) ====
  * **Former Java Class:** BellaNPC.java (deleted)
  * **Base Class:** ImmortalNPC
  * **Interaction:** Handled by the `interact` method
  * **String Resources:** Still exist in strings_all.xml for multiple languages
