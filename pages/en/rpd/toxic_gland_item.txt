====== Toxic Gland ======

{{ rpd:images:toxic_gland_item.png|Toxic Gland }}

The **Toxic Gland** is a crafting material in Remixed Dungeon harvested from defeated enemies. It serves as an alchemical ingredient and is primarily obtained by the Doctor class through the Bone Saw's critical hit harvesting mechanic.

==== Description ====
A toxic gland harvested from a defeated enemy. These glands are filled with potent toxins and can be used in alchemical processes.

==== Properties ====
  * **Type**: Material / Crafting Component
  * **Stackable**: Yes
  * **Cost**: 0 gold (Doctor harvest: not sellable)
  * **Sprite**: Image 3 from `items/materials.png`

==== Acquisition ====
  * **Doctor Class**: Critical hits with the [[en:rpd:bone_saw_item|Bone Saw]] have a chance to harvest Toxic Glands from corpses (along with [[en:rpd:rotten_organ_item|Rotten Organ]] and [[en:rpd:bone_shard_item|Bone Shard]])
  * **Carcass Interaction**: Using the Bone Saw on carcasses yields harvestable materials

==== Uses ====
  * **Alchemy**: Used as an ingredient in alchemical recipes (see `scripts/alchemy_recipes.json`)
  * **Crafting Component**: Material for various crafting processes

==== Implementation Details ====
The Toxic Gland is implemented as a Lua scripted item:
  * **Lua Script**: `scripts/items/ToxicGland.lua`
  * **Harvest Logic**: `scripts/items/BoneSaw.lua` (critical hits drop ToxicGland, RottenOrgan, or BoneShard)
  * **Alchemy Recipes**: `scripts/alchemy_recipes.json`
  * Uses the item library via `require "scripts/lib/item"`
  * Not a Java class - fully data-driven via Lua
