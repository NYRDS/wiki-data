====== One-Way Love ======

{{ rpd:images:one_way_cursed_love_buff.png|One-Way Love }}

**One-Way Love** is a buff applied by the [[en:rpd:dried_rose_item|Dried Rose]] when it is **not cursed**.

==== Effects ====
  * **Charmed** - The rose appears beautiful but not very enchanting
  * Causes the user to be charmed in a one-way direction

==== Notes ====
  * This effect applies when the [[en:rpd:dried_rose_item|Dried Rose]] is **not cursed**
  * The effect is part of the ghost questline
  * Affects how NPCs interact with the player
  * Uses the same icon as the cursed version but different buff indicator
