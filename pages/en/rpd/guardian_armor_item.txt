====== Guardian Armor ======

{{ rpd:images:guardian_armor_item.png|Guardian Armor }}

The **Guardian Armor** is the class-specific armor for the [[en:rpd:gnoll_class|Gnoll]] class, particularly associated with the Guardian subclass. Though the code indicates it was intended for the Guardian subclass (commented check), currently only the Gnoll class can equip it. It inherits the **Domination** special ability from its parent class `GnollArmor`.

==== Item Overview ====
  * **Type:** Class Armor
  * **Class:** [[en:rpd:gnoll_class|Gnoll]]
  * **Subclass:** [[en:rpd:guardian_subclass|Guardian]] (intended, but not enforced in current code)
  * **Special Effect:** **Domination** — charms nearby hostile mobs within line of sight (up to hero level / 6 mobs)
  * **Visual:** Has helmet, covers hair (distinct from base Gnoll Armor)
  * **Sprite index:** 26 (vs 25 for base Gnoll Armor)

==== Special Ability: Domination ====
Inherited from `GnollArmor`:
  * **Effect:** Charms hostile mobs within line of sight and maximum shadow casting distance
  * **Limit:** Maximum charmed mobs = hero level / 6
  * **Visual:** Domination spell sprite effect on hero, flare effect on charmed mobs
  * **Sound:** Dominance sound (SND_DOMINANCE)
  * **Cooldown:** One turn (user.spend(Actor.TICK))
  * **Note:** The armor does NOT have unique "protection/defensive mechanics" or "shield synergy" — these were incorrect descriptions. It uses the same Domination ability as base Gnoll Armor.

==== Obtaining ====
  * Available as a class armor for the Gnoll class via the [[en:rpd:tengu_liver_item|Tengu Liver]] which allows choosing between [[en:rpd:guardian_subclass|Guardian]] and [[en:rpd:witchdoctor_subclass|Witch Doctor]] subclasses
  * Can be crafted using an [[en:rpd:armor_kit_item|Armor Kit]] on regular armor of the same tier

==== Strategy ====
  * Effective for controlling groups of enemies by turning them into temporary allies
  * Synergizes with builds that benefit from having pet mobs
  * Note: The current implementation in code only allows Gnoll class to equip it, though the commented code suggests it was intended for the Guardian subclass specifically
