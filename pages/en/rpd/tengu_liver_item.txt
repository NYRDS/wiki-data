====== Tengu Liver ======
{{ rpd:images:tengu_liver_item.png|Tengu Liver }}

**Tengu Liver** is a special consumable item dropped by Tengu when playing as the Gnoll class. It allows the Gnoll hero to choose a subclass.

==== Function ====
  * **Subclass Selection**: When consumed by a Gnoll hero, opens a choice between **Guardian** and **WitchDoctor** subclasses
  * **Consumable**: Single-use item that is consumed when used
  * **Class-specific**: Only dropped for and usable by Gnoll heroes

==== Acquisition ====
  * **[[en:rpd:tengu_mob|Tengu]]**: Dropped by Tengu specifically when playing as the Gnoll class (guaranteed if not already obtained)
  * **Uniqueness**: Only obtainable by Gnoll class heroes

==== Effects ====
  * **Subclass Unlock**: Allows Gnoll to choose between Guardian or WitchDoctor subclass via Tome of Mastery interface
  * **Permanent Choice**: Once a subclass is selected, it cannot be changed
  * **No Effect on Other Classes**: Item has no effect if consumed by non-Gnoll heroes (though it's not normally obtainable by them)

==== Strategy ====
  * **Class-Synergy**: Exclusive to Gnoll players - essential for unlocking subclass
  * **Timing**: Can be consumed immediately or saved for later; the choice is permanent
  * **Subclass Benefits**: Guardian provides defensive/tank mechanics; WitchDoctor provides plague/poison mechanics
