====== Wand of Blink ======

{{ rpd:images:wand_of_blink_item.png|Wand of Blink }}

==== Description ====
The Wand of Blink allows the user to teleport to a target location. The distance of the blink depends on the wand's level and the distance to the target. If the target cell is occupied, the blink will end at a safe distance from the target. If the target is too far away, the blink will end at a shorter distance based on the wand level.

==== Mechanics ====
When zapped, the Wand of Blink:
  * Teleports the user to the target location
  * Maximum range equals wand level + 4 cells
  * If target is too far, blinks to maximum range
  * If target cell is occupied, blinks to nearest safe cell
  * Produces white light magic missile visual effect
  * Plays teleport sound effect
  * Emits light speck particles on arrival

==== Properties ====
  * **Maximum Range**: Wand level + 4 cells
  * **Targeting**: Self-cast only (does not affect target)
  * **Visual Effects**: White light magic missile, teleport sound, light specks
  * **Path Calculation**: Uses Ballistica for line-of-sight and distance

==== Strategy ====
  * Useful for escaping dangerous situations or repositioning in combat
  * Can teleport through walls if there's line of sight
  * Maximum range increases with wand upgrades
  * Cannot target enemies directly - only empty cells
