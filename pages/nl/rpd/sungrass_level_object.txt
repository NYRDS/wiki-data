====== Zonnegras Level Object ======

{{ rpd:images:sungrass_level_object.png|Zonnegras Level Object }}

==== Beschrijving ====
Het zonnegas level object biedt genezing over tijd aan elk personage dat het aanraakt. Wanneer een personage op de tegel met een zonnegas level object stapt, begint het een genezend effect te bieden over meerdere beurten.

==== Effecten ====
  * Biedt genezing over tijd aan het personage dat het aanraakt
  * Biedt aanhoudend herstel van gezondheid
  * Het genezende effect blijft over meerdere beurten doorgaan
  * Het level object verdwijnt na aanraking

==== Mechanica ====
  * Zonnegras level objects kunnen in de kerker groeien
  * Ze kunnen ook worden gekweekt door [[nl:rpd:sungrass_seed_item|Zonnegras Zaden]] te planten
  * Het genezende effect treedt op over een duur na aanraking
  * Bijzonder waardevol wanneer gezondheid laag is

==== Strategie ====
  * Zonnegras level objects zijn extreem waardevol voor genezing wanneer gezondheid laag is
  * Ze zijn in sommige situaties effectiever dan directe genezing
  * Overweeg ze te bewaren voor wanneer genezing het meest nodig is
  * Beter dan directe genezing wanneer je tijd hebt om het effect te laten werken
