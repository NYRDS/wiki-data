===== Lua Script =====
File: `RemixedDungeon/src/main/assets/scripts/npc/FortuneTeller.lua`
Key behaviors implemented in Lua:
  * **interact**: Opens identification dialog with two options:
    * Identify single item for 50 gold (modified by difficulty and Ring of Haggler)
    * Identify all unidentified items for 50 gold per item
  * Uses `RPD.CharUtils:goldPrice(chr, 50)` for dynamic price calculation
  * Uses `RPD.CharUtils:countUnidentified(chr)` to count unidentified items
  * Uses `RPD.CharUtils:identifyItem(chr, item)` for single item identification
  * Uses `chr:getBelongings():identify()` for identify all
  * Uses `RPD.chooseOption()` for dialog with options
  * Validates gold before proceeding

===== Code Implementation =====
This NPC/window is implemented via JSON configuration + Lua script (migrated from Java classes `com/nyrds/pixeldungeon/mobs/npc/FortuneTellerNPC.java` and `com/nyrds/pixeldungeon/windows/WndFortuneTeller.java`).

Key mechanics:
  * **Identification Cost**: 50 gold per item (base), modified by `RPD.CharUtils:goldPrice()` which applies difficulty multiplier and Ring of Haggler discount (10%)
  * **Single Item**: Player selects one unidentified item to identify
  * **All Items**: Identifies all unidentified items in inventory at once
  * **Gold Validation**: Checks if player has enough gold before proceeding
  * **Alternative to Scrolls**: Provides alternative to [[en:rpd:scroll_of_identify_item|Scroll of Identify]]

===== Behavior =====
  * Stationary NPC found in Town level (Fortune level)
  * Passive AI - does not initiate combat
  * Immortal - cannot be killed
  * Offers identification services for gold
  * Uses game's window system for dialog interaction
