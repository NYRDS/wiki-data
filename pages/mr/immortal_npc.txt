====== Immortal NPC - Code References ======

===== Java Classes =====
This entity type no longer exists as a Java base class. NPC immortality is now configured per-entity via JSON in `mobsDesc/` with `"immortal": true`. The former `ImmortalNPC.java` abstract class has been removed.

===== JSON Configuration =====
Immortality and related NPC properties are defined in individual NPC JSON files in `RemixedDungeon/src/main/assets/mobsDesc/`. Common properties for immortal NPCs:
  * `"immortal": true` - Prevents damage and death
  * `"movable": false` - NPC cannot move
  * `"defenseSkill": 1000` - Effectively impossible to hit
  * `"baseSpeed": 0` or `0.5` - Immobile or very slow
  * `"aiState": "Passive"` - Non-aggressive behavior
  * `"fraction": "NEUTRAL"` - Neutral faction
  * `"defenceVerb": "Ghost_Defense"` - Uses "wails" as defense verb
  * `"persistOnReset": true` - Survives level resets
  * `"npc": true` - Marks as NPC type
  * `"friendly": true` - Friendly to player

Example: [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/assets/mobsDesc/TownsfolkNPC.json|TownsfolkNPC.json]], [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/assets/mobsDesc/ServiceManNPC.json|ServiceManNPC.json]]

===== String Resources =====
  * [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/res/values/strings_all.xml|Ghost_Defense]] - "wails" (used as defenceVerb)

===== Lua Scripts =====
NPC behaviors are implemented in Lua scripts in `scripts/npc/` (e.g., `scripts/npc/Townsfolk.lua`, `scripts/npc/Healer.lua`)
