===== JSON Configuration =====
This entity is implemented in Java, no JSON configuration exists for the base MeleeWeapon class.
Individual melee weapons may have JSON configuration in Treasury.json for loot tables.

===== String Resources =====

Russian string resources (values-ru/strings_all.xml) provide localization for all melee weapons.

===== Lua Scripts =====

Custom melee weapons may use Lua scripts in scripts/items/.

===== Weapon Stats =====
  * **Damage Range**: Varies by weapon (e.g., ShortSword: 1-4, Dagger: 1-3)
  * **Speed**: Varies by weapon (e.g., ShortSword: 1.0, Dagger: 1.3)
  * **Accuracy**: Varies by weapon (e.g., ShortSword: 1.0, Dagger: 1.1)
  * **Required Strength**: Calculated based on tier
  * **Durability**: Degrades on use, can be repaired
  * **Upgradeable**: Can be upgraded with Scroll of Upgrade
