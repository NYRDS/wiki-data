===== Java Classes =====
  * No dedicated Java class (replaced by Lua implementation in migration batch 16c-2)

===== Lua Scripts =====
  * [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/assets/scripts/npc/Imp.lua|Imp.lua]] - NPC implementation with quest logic
  * Uses libraries: `scripts/lib/commonClasses`, `scripts/lib/quest`, `scripts/lib/mob`

===== Quest Configuration (from Lua) =====
  * **Quest ID:** "imp"
  * **Quest State Storage:** lib/quest game storage under "imp" key
  * **Quest Variants:** Two alternatives (Monk hunt or Golem hunt)
  * **Monk Variant:** Kill 8 Monks (Monk entity kind)
  * **Golem Variant:** Kill 6 Golems (Golem entity kind)
  * **Kill Tracking:** Via onDie callback - drops DwarfToken from Monk/Golem deaths
  * **Exclusions:** Palace servants and raised undead do not count
  * **Quest State Fields:** spawned, given, completed, alternative

===== Reward (from Lua) =====
  * **Reward Item:** Random ring from level treasury (RING category)
  * **Ring Constraints:** Never cursed initially, upgraded twice, then re-cursed
  * **Generation:** Lazy at reward time (treasury:random("RING"))
  * **Identification:** Auto-identified on reward

===== Spawn Locations =====
  * **Placement:** CityLevel (depth 17+)
  * **Placement Logic:** Handled by CityLevel painter
