===== Additional Information =====
  * The RingOfStoneWalking extends Artifact (not Ring base class)
  * When equipped, applies the StoneWalking buff (ArtifactBuff implementing Doom)
  * StoneWalking buff:
    - Icon: BuffIndicator.STONEBLOOD
    - Name/desc from string resources: StoneBloodBuff_Name, StoneBloodBuff_Info
    - On hero death: validates DeathInStone badge, fails game with "immured in stone" message
  * Stored in keyring bag (Bag.KEYRING)
  * Identified by default (identify() called in constructor)
  * Image: ItemSpriteSheet.RING_OF_STONE_WALKING (index 133)
  * The buff effect allows walking through solid walls
  * Health cost per step in walls: max(currentHP / 2, 2)
  * Does not function on boss levels (checked in movement logic)
  * Death while buffed results in "immured in stone" game over
