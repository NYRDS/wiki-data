===== Affinity Implementation =====
In SpellHelper.java:
  * `affinityToIcon.put("Combat", 15);` - Maps Combat affinity to icon ID 15
  * `iconIdByAffinity()` method returns icon ID based on affinity string

In HeroClass.java:
  * `magicAffinity` field stores the hero class's default affinity
  * `getMagicAffinity()` / `setMagicAffinity()` accessor methods
