===== Lua Script =====
File: `RemixedDungeon/src/main/assets/scripts/mobs/YogsEye.lua`
Key behaviors implemented in Lua:
  * **canAttack**: Uses Ballistica to cast gaze ray from one row above eye position
  * **zapProc**: Beams strike through all characters in line (Eye_Kill effect)
  * **damage**: Calls other Yog organs to position; damage reduced by 2^shift where shift = number of living organs
  * **die**: Validates YOG_SLAIN badge; yells Yog_Info1
  * **notice**: Yells Yog_Info2
  * **spawn**: Spawns 2-3 other Yog organs (RottingFist, BurningFist, YogsBrain, YogsHeart, YogsTeeth) on battle start
  * Spawns Larva when damaged (10 * difficulty factor)

===== Code Implementation =====
This mob is implemented via JSON configuration + Lua script (migrated from Java class `com/nyrds/pixeldungeon/mobs/guts/YogsEye.java`).

Key properties from JSON:
  * **HP**: 1000 (ht)
  * **Attack Skill**: 30
  * **Defense Skill**: 30
  * **Damage**: 20-30
  * **STR**: 18
  * **EXP**: 50
  * **Max Level**: 50
  * **Immobile**: movable = false
  * **Boss**: isBoss = true
  * **Immunities**: Death, Terror, Amok, Charm, Sleep, Burning, Toxic Gas, Psionic Blast
  * **Resistances**: Death, Psionic Blast

Special abilities from Lua:
  * **Death Ray / Gaze**: Attacks along a straight line (Ballistica cast from cell above)
  * **Organ Coordination**: When damaged, calls all living Yog organs (RottingFist, BurningFist, YogsBrain, YogsHeart, YogsTeeth) to its position
  * **Organ Protection**: Incoming damage is halved per living organ (damage >>= shift)
  * **Larva Spawn**: Spawns Larva when taking damage (count based on difficulty)
  * **Secondary Organ Spawning**: At battle start, spawns 2-3 distinct other Yog organs (3 on difficulty > 2, else 2)
  * **Boss Death Flow**: Awards YOG_SLAIN badge on death

===== Behavior =====
  * Remains stationary throughout the battle (movable = false)
  * Cannot be beckoned (no beckon override in Lua, but JSON movable=false prevents movement)
  * Automatically spawns 2-3 secondary boss organs at battle start
  * Uses death ray attack that affects all characters in a straight line
  * Damage reduction scales with number of surviving sibling organs
  * On death, awards badge for Yog-Dzewa being slain
