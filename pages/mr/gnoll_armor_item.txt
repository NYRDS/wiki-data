===== Mechanics =====
**Special Ability - DOMINATE (DOMINEREN / ДОМИНИРОВАНИЕ):**
  * Activated via the armor's special action
  * Shows DOMINATION spell sprite effect
  * Plays dominance sound effect
  * Charms nearby mobs that canBePet() within line of sight and ShadowCaster.MAX_DISTANCE
  * Maximum dominated mobs = hero level / 6
  * Costs one turn (Actor.TICK)

**Equip Restriction:**
  * Only heroes with HeroClass.GNOLL can equip
  * Other classes receive warning message: "Only gnolls can equip the Gnoll Aror!"
  * Subclass variants (GuardianArmor, WitchdoctorArmor) maintain same restriction

**Visual Properties (Base GnollArmor):**
  * image = 25 (ItemSpriteSheet index)
  * coverHair = false
  * hasCollar = false
  * hasHelmet = false

**Visual Properties (GuardianArmor):**
  * image = 26
  * hasHelmet = true
  * coverHair = true

**Visual Properties (WitchdoctorArmor):**
  * image = 27
  * hasHelmet = true
  * coverHair = true
  * coverFacialHair = true
