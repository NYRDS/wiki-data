====== Weapon Enchantments - Code References ======

{{ rpd:images:enchantment.png|Weapon Enchantments}}

===== Overview =====
Weapon enchantments are special magical properties that can be added to weapons via [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/watabou/pixeldungeon/items/scrolls/ScrollOfEnchantment.java|ScrollOfEnchantment.java]]. Each enchantment is implemented as a Lua script in `scripts/enchants/` and extends the base [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/watabou/pixeldungeon/items/weapon/Weapon.java|Weapon.Enchantment]] class (Java).
