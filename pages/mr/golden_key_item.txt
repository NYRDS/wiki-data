===== Lua Scripts =====
This entity is implemented in Java, no Lua script exists

===== Usage =====
  * Opens LOCKED_CHEST and CRYSTAL_CHEST heaps, checked in OpenChest.java via ''getKey(GoldenKey.class, ...)''
  * Part of the key family of items; stored in the Keyring bag (''bag()'' returns Keyring)
  * Cannot be upgraded; carries a ''levelId'' so it only opens chests on the level where it was found
  * Shows its depth in the status line (''status()'' returns depth)
