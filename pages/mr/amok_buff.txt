===== Lua Scripts =====

**Key Implementation Details:**
  * Lua buff module using `scripts/lib/buff` library
  * Icon: `9` (BuffIndicator.AMOK)
  * Name string: `AmokBuff_Name`
  * Info string: `AmokBuff_Info`
  * Visual status: `CharSprite.NEGATIVE` (red text)
  * Status text: `Char_StaAmok` string resource

**Core Functions:**
  * `desc()` - Returns buff descriptor with icon, name, and info strings
  * `attachVisual()` - Shows "AMOK" status text on target when buff is applied
