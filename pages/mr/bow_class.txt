====== Bow Class - Machine Readable Reference ======

===== Description =====
The **Bow** abstract class (`com.nyrds.pixeldungeon.items.guts.weapon.ranged.Bow`) serves as the base class for all bow weapons in the guts package. It extends `KindOfBow` and provides a common constructor for bow tiers, accuracy, and delay.

===== Entity Information =====
  * **Entity Kind:** Bow (abstract class)
  * **Type:** Weapon Base Class (Ranged)
  * **Package:** com.nyrds.pixeldungeon.items.guts.weapon.ranged
  * **Category:** Ranged Weapons Base

public Bow(int tier, float acu, float dly) {
    super(tier, acu, dly);
    animation_class = BOW_ATTACK;

// Inherited from KindOfBow:
// tier - Weapon tier (affects damage, STR requirement)

// dly - Base attack delay (e.g., 1.5f for Compound Bow)
// arrowType - Type of arrow used (default: "Arrow")

===== Modding Considerations =====
  * Extend this class for custom bow types in the guts package
  * Override `acuFactor()`, `dmgFactor()`, `dlyFactor()` for custom scaling
  * Compatible with standard arrow mechanics
  * Uses `BOW_ATTACK` animation class
  * Requires arrows to function (handled by KindOfBow)

===== Implementation Notes =====
  * Abstract class - cannot be instantiated directly
  * Provides guts-package alternative to standard bow hierarchy
  * Sets animation_class to BOW_ATTACK for proper rendering
  * Delegates arrow selection/management to KindOfBow
  * Damage calculation follows MeleeWeapon tier formula modified by dmgFactor()
