===== Plant Behavior =====
  * **Trigger:** When a character steps on the Earthroot plant
  * **Effect:** Applies "Armor" buff to the character
  * **Buff Level:** Set to character's max HP (HT)
  * **Visual Effect:** Earth particles and camera shake
  * **Buff Properties:** Absorbs damage up to level amount, detaches if character moves from the cell

===== Buff Implementation (Armor) =====
<code lua>
defenceProc = function(self, buff, enemy, damage)
    local lvl = buff:level()
    if damage >= lvl then
        buff:detach()
        return damage - lvl
    else
        buff:level(lvl - damage)
        return 0
    end
end
</code>
