===== Key Fields =====
  * `tier` (int) - Armor tier (1-6+), determines base DR and STR requirement
  * `glyph` (Glyph) - Inscribed glyph/enchantment (nullable)
  * `hasHelmet`, `hasCollar`, `coverHair`, `coverFacialHair` - Visual properties
  * `hitsToKnow` (int) - Hits needed to auto-identify armor level (default 10)

===== Key Methods =====
  * `slot(Belongings)` - Returns `Belongings.Slot.ARMOR`
  * `upgrade(boolean inscribe)` - Upgrades armor, may randomly add/remove glyph
  * `defenceProc(Char attacker, Char defender, int damage)` - Damage reduction with glyph proc
  * `effectiveDr()` - Effective damage reduction: `tier * 2 + level() * tier + (glyph != null ? tier : 0)`
  * `typicalDR()` - Base DR: `tier * 2`
  * `typicalSTR()` - Base STR requirement: `7 + tier * 2`
  * `requiredSTR()` - Actual STR needed: `max(typicalSTR() - level(), 2)`
  * `price()` - Shop price: `10 * (1 << (tier - 1))`, 1.5x with glyph
  * `inscribe(Glyph)` - Adds glyph to armor
  * `random()` - Generates random armor, 10% chance of random glyph
  * `info()` / `name()` / `toString()` - Display logic with identification state

===== Armor Glyphs (Inner Class) =====
Abstract class `Armor.Glyph` extends `Buff`, implements `Bundlable`, `NamedEntityKind`, `Doom`
  * 10 glyph types with equal weight: Bounce, Affection, AntiEntropy, Multiplicity, Potential, Metabolism, Stench, Viscosity, Displacement, Entanglement
  * `defenceProc(Armor, Char, Char, int)` - Abstract, implemented per glyph
  * `onHeroDeath()` - Validates GLYPH death badge, shows death message
