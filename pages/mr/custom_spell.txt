===== Class Implementation Details =====
CustomSpell extends the base Spell class and loads all spell properties from a Lua script:

**Constructor** (`CustomSpell(String scriptFile)`):
  - Loads Lua script from `scripts/spells/{scriptFile}`
  - Runs `spellDesc()` function to get spell descriptor table
  - Extracts properties: image, imageSize, imageFile, name, info, magicAffinity, targetingType, cooldown, level, spellCost, castTime

**Casting Methods**:
  - `cast(Char chr, int cell)` - Runs Lua `castOnCell(chr, cell)`
  - `cast(Char chr, Char target)` - Runs Lua `castOnChar(chr, target)`
  - `cast(Char chr)` - Runs Lua `cast(chr)` (for self-targeted spells)
  - All call `castCallback(chr)` on success

**Other Methods**:
  - `getEntityKind()` - Returns the script file name
  - `getImage()` - Can be overridden by Lua `image()` function
