====== Subclasses de Herói ======

Subclasses de herói são caminhos de especialização avançados disponíveis para classes de herói em Remixed Dungeon.

==== Descrição ====
Subclasses de herói representam caminhos de maestria que se tornam disponíveis após completar conquistas específicas com certas classes de herói. Elas fornecem habilidades especiais adicionais e estilos de jogo diferentes para jogadores avançados.

==== Subclasses Disponíveis ====
  * **Subclasses do Guerreiro:**
    * [[pt:rpd:gladiator_subclass|Gladiador]] - Para classe Guerreiro, foca em maestria de armas
    * [[pt:rpd:berserker_subclass|Berserker]] - Para classe Guerreiro, foca em combate quando com pouca vida
  * **Subclasses do Mago:**
    * [[pt:rpd:battle_mage_subclass|Mago de Batalha]] - Para classe Mago, combina combate e magia
    * [[pt:rpd:warlock_subclass|Bruxo]] - Para classe Mago, foca em magia de drenagem de vida
  * **Subclasses do Ladino:**
    * [[pt:rpd:freerunner_subclass|Corredor Livre]] - Para classe Ladino, velocidade e furtividade aprimoradas
    * [[pt:rpd:assassin_subclass|Assassino]] - Para classe Ladino, focado em causar alto dano
  * **Subclasses do Elfo:**
    * [[pt:rpd:shaman_subclass|Xamã]] - Para classe Elfo, especializado em magia elemental
    * [[pt:rpd:scout_subclass|Batedor]] - Para classe Elfo, focado em combate à distância e detecção
  * **Subclasses do Necromante:**
    * [[pt:rpd:lich_subclass|Lich]] - Para classe Necromante, poderes necromânticos aprimorados
  * **Subclasses do Gnoll:**
    * [[pt:rpd:guardian_subclass|Guardião]] - Para classe Gnoll, foca em defesa e proteção
    * [[pt:rpd:witch_doctor_subclass|Médico Bruxo]] - Para classe Gnoll, foca em lançamento de feitiços e escudo mágico

==== Mecânicas de Subclasse ====
  * **Desbloqueio:** Subclasses são desbloqueadas derrotando chefes específicos com a classe apropriada
  * **Habilidades Especiais:** Cada subclasse concede habilidades ativas únicas
  * **Mudanças de Equipamento:** Algumas subclasses vêm com equipamentos ou itens únicos
  * **Mudanças de Estilo de Jogo:** Cada subclasse muda como a classe é jogada

==== Requisitos de Desbloqueio ====
  * **Gladiador/Berserker:** Derrotar Tengu com classe Guerreiro
  * **Mago de Batalha/Bruxo:** Derrotar Tengu com classe Mago
  * **Corredor Livre/Assassino:** Derrotar Tengu com classe Ladino
  * **Xamã/Batedor:** Derrotar Tengu com classe Elfo
  * **Lich:** Derrotar Yog-Dzewa com classe Necromante
  * **Guardião/Médico Bruxo:** Derrotar Tengu com classe Gnoll
