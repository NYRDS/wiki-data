====== Buf de Artefato ======

{{ rpd:images:ring_of_stone_blood_item.png|Buf de Artefato }}

===== Descrição =====
O **Buf de Artefato** é uma classe base para bufs relacionados a artefatos no Remixed Dungeon. Ele estende a classe padrão [[pt:rpd:buff_mechanics|Buf]] e adiciona comportamento específico para bufs originados de artefatos.

===== Principais Características =====
  * **Rastreamento de Origem:** Cada BufDeArtefato rastreia o ID de sua entidade origem via `getSourceId()`
  * **Desanexação Automática:** Se o ID da origem for `EntityIdSource.INVALID_ID` (significando origem não-arquivo), o buf se desanexa automaticamente
  * **Persistência:** BuFos de artefato com IDs de origem válidos não são empacotados/salvos com o estado do jogo (`dontPack()` retorna `true`)
  * **Tipo de Entidade:** Retorna "artifactBuff" + tipo de entidade do pai para identificação única

===== Implementação em Código =====
<code java>
public class ArtifactBuff extends Buff {

    @Override
    public void act() {
        if(getSourceId()==EntityIdSource.INVALID_ID) { // origem não-arquivo
            detach();
        }
        super.act();
    }

    public String getEntityKind() {
        return "artifactBuff" + super.getEntityKind();
    }

    @Override
    public boolean dontPack() {
        return getSourceId()!= EntityIdSource.INVALID_ID;
    }
}
</code>
