====== Nid d'Araignée ======

{{ rpd:images:spider_nest_mob.png|Nid d'Araignée }}

==== Description ====
Le **Nid d'Araignée** est un mob spécial trouvé dans le niveau Nid d'Araignée de Remixed Dungeon. Contrairement aux autres mobs, cette créature est stationnaire et fait périodiquement apparaître de petites araignées pour défendre la zone.

==== Stats ====
  * **PV** : 10 (PV max : 10) (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L8|SpiderNest.java#L8]])
  * **Compétence de Défense** : 2 (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L13|SpiderNest.java#L13]])
  * **Compétence d'Attaque** : 1 (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L12|SpiderNest.java#L12]])
  * **Vitesse** : 0 (immobile) (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L9|SpiderNest.java#L9]])
  * **Dégâts** : 0-0 (n'attaque pas directement) (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L11|SpiderNest.java#L11]])

  * **EXP pour Kill** : 0 (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L10|SpiderNest.java#L10]])
  * **Niveau Max** : 9 (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L10|SpiderNest.java#L10]])

==== Capacités ====
  * **Apparition d'Araignées** : Fait apparaître régulièrement des araignées aléatoires pour défendre le nid (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L20-L24|SpiderNest.java#L20-L24]])
  * **Immobilisé** : Le nid ne peut pas bouger (movable = false) (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L17|SpiderNest.java#L17]])

==== Mécaniques Spéciales ====
  * Fait apparaître continuellement des araignées aléatoires pour protéger la zone (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L20-L24|SpiderNest.java#L20-L24]])
  * Ne peut pas être apprivoisé comme familier (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L27-L29|SpiderNest.java#L27-L29]])

==== Butin ====
  * **Potion de Soin** (20% de chance) : Potion de soin aléatoire (source : [[https://github.com/NYRDS/remixed-dungeon/blob/master/RemixedDungeon/src/main/java/com/nyrds/pixeldungeon/mobs/spiders/SpiderNest.java#L16|SpiderNest.java#L16]])

==== Emplacement ====
  * Trouvé dans le niveau Nid d'Araignée
