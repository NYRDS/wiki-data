====== Potion de Gaz Toxiques ======

{{ rpd:images:potion_of_toxic_gas_item.png|Potion de Gaz Toxiques }}

**Potion de Gaz Toxiques** est une potion utilitaire dans Remixed Dungeon qui crée un nuage de gaz toxique lorsqu'elle est lancée.

==== Description ====
Lorsque cette potion est lancée sur un emplacement, elle crée un nuage de gaz toxique qui endommage tout personnage restant dans la zone. Contrairement aux autres potions, elle est généralement utilisée comme outil tactique plutôt que pour un bénéfice personnel.

==== Effets ====
  * **Création de Gaz** : Crée un nuage de gaz toxique à l'emplacement cible
  * **Dégâts sur la Durée** : Les personnages dans le nuage de gaz subissent des dégâts chaque tour
  * **Effet de Zone** : Affecte une petite zone autour du point d'impact
  * **Durée** : Le nuage de gaz persiste pendant plusieurs tours

==== Statistiques ====
  * **Type** : Potion Utilitaire
  * **Rareté** : Peu Commune
  * **Poids** : 10 unités
  * **Identifiée** : Nécessite une identification pour révéler l'effet
  * **Cible** : Lancée sur une tuile (pas d'auto-utilisation)

==== Utilisation ====
  * **Combat** : Utilisée pour endommager des groupes d'ennemis
  * **Tactique** : Création de barrières de gaz toxique pour contrôler le mouvement des ennemis
  * **Urgence** : Utilisée quand on est encerclé pour créer une route de fuite
  * **Déni de Zone** : Bloquer des passages ou points d'étranglement avec du gaz

==== Stratégie ====
  * **Positionnement** : Considérez où la lancer pour affecter plusieurs ennemis
  * **Direction du Vent** : Si applicable, considérez comment les nuages de gaz pourraient se propager
  * **Types d'Ennemis** : Particulièrement efficace contre les ennemis à faible vie
  * **Autopréservation** : Attention à ne pas vous piéger vous-même dans les nuages de gaz

==== Acquisition ====
  * **Trouvée dans** : Coffres de donjon réguliers et magasins
  * **Lâchée par** : Divers ennemis
  * **Alchimie** : Potentiellement fabriquable si des recettes existent
