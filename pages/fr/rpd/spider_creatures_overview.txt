====== Araignées ======

{{ rpd:images:spider_queen_mob.png|Reine des Araignées }}

==== Description ====
Les araignées sont une famille de créatures dans Remixed Dungeon qui inclut divers types d'arachnides. Elles vont de petites créatures faibles à de puissants boss comme la [[fr:rpd:spider_queen_mob|Reine des Araignées]].

==== Types d'Araignées ====
  * **Araignées Régulières** : Ennemis communs trouvés dans tout le donjon
  * **Serviteurs Araignées** : Variantes plus puissantes
  * **Araignées Explosives** : S'autodétruisent quand elles sont menacées
  * **Gardes Araignées** : Variantes défensives d'araignées
  * **Esprit Araignée** : Araignées avec des capacités de contrôle mental
  * **Reine des Araignées** : Le boss araignée
  * **Nid d'Araignée** : Structures qui font apparaître d'autres araignées

==== Propriétés Spéciales ====
  * De nombreuses créatures araignées peuvent créer des toiles
  * Certaines interagissent avec le terrain [[fr:rpd:web_trap|Toile]]
  * Les objets liés aux araignées incluent l'[[fr:rpd:spider_armor_item|Armure d'Araignée]] qui permet de se déplacer sur le terrain toile
