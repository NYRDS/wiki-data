====== Poción ======

{{ rpd:images:potion_of_healing_item.png|Poción }}

**Poción** es la clase base para todos los objetos de poción en Remixed Dungeon.

==== Descripción ====
Las pociones son objetos consumibles que proporcionan varios efectos beneficiosos o perjudiciales cuando se consumen. Algunas pociones solo se pueden consumir, mientras que otras se pueden lanzar a enemigos o al terreno para crear efectos de área.

==== Propiedades Base ====
  * **Apilable**: Sí - las pociones se pueden apilar hasta 6 objetos por ranura
  * **Tipo**: Objeto consumible con varios efectos
  * **Almacenamiento**: Se pueden guardar en el Cinturón de Pociones si está disponible
  * **Identificación**: La mayoría de las pociones comienzan sin identificar y deben usarse para volverse conocidas

==== Tipos de Pociones ====
  * **Pociones Beneficiosas** - Proporcionan efectos positivos como curación o mejoras de estadísticas
  * **Pociones Perjudiciales** - Crean efectos negativos que pueden ser útiles contra enemigos
  * **Pociones de Utilidad** - Proporcionan efectos ambientales o situacionales especiales

==== Mecánicas Comunes ====
  * **Identificación**: Las pociones se identifican después de usarse (consumirlas o lanzarlas)
  * **Lanzamiento**: La mayoría de las pociones se pueden lanzar para crear efectos de área
  * **Alquimia**: Algunas pociones se pueden usar en recetas de alquimia
  * **Elaboración**: Las pociones se pueden combinar con semillas para crear nuevos objetos
