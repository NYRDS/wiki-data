====== 薩滿 專精 ======

{{ rpd:images:elf_shaman_hero.png|薩滿 }}

薩滿是 Remixed Dungeon 中 [[zh:rpd:elf_class|精靈]] 職業的專精。

===== 簡介 =====
精靈 //薩滿// 可以將魔杖作為近戰武器使用。成功命中時有機率在不消耗充能的情況下，對目標發動魔杖的力量。

===== 解鎖方式 =====
擊敗第二個首領 (天狗) 後，使用 [[zh:rpd:tome_of_mastery_item|掌握之書]] 即可解鎖薩滿專精。

===== 特殊機制 =====
  * 精靈 _薩滿_ 可以將 [[zh:rpd:wands|魔杖]] 作為 [[zh:rpd:melee_weapons|近戰武器]] 使用
  * 當裝備魔杖作為主武器攻擊時，有 25% 的機率 (實現為 Random.Int(4) == 0) 對目標發動魔杖力量而不消耗充能
  * 此能力在 HeroSubClass.java 的 attackProc 方法中實現 (第 172-181 行)
  * 魔杖必須裝備為主武器 (作用中武器) 此機制才生效
  * 魔杖需有可用充能且 affectTarget() 方法必須回傳 true
  * +1 露水加成增強 [[zh:rpd:mana_mechanic|魔力恢復]]
  * **mr: 命名空間：** 查看 [[mr:shaman_subclass]] 獲取機器可讀數據

===== 技術細節 =====
  * **實現方式**：薩滿的特殊機制在 HeroSubClass.java 的 attackProc 方法中實現 (第 172-181 行)
  * **魔杖發動**：當薩滿裝備魔杖作為作用中武器攻擊時，有 25% 機率對敵人發動魔杖效果而不消耗充能
  * **程式碼參考**：具體實現檢查主武器是否為魔杖，若 affectTarget() 回傳 true 且 Random.Int(4) == 0，則呼叫 zapCell() 對敵人發動效果而不消耗充能

===== 專屬護甲 =====
使用 [[zh:rpd:armor_kit_item|護甲套裝]] 將任何護甲轉換為 [[zh:rpd:shaman_armor_item|薩滿護甲]]，專為此專精設計。

===== 優勢 =====
  * 可以將 [[zh:rpd:wands|魔杖]] 作為 [[zh:rpd:melee_weapons|近戰武器]] 使用
  * 25% 機率在不消耗充能下發動魔杖力量
  * 結合 [[zh:rpd:ranged_weapons|遠程]] 和 [[zh:rpd:melee_combat|近戰]] 的多功能武器選擇
  * 魔杖力量發動時保留充能
  * 與所有 [[zh:rpd:wands|魔杖類型]] 協同良好
  * +1 露水加成增強 [[zh:rpd:mana_mechanic|魔力恢復]]

===== 劣勢 =====
  * 發動機率不保證 (25% 機率)
  * 魔杖作為 [[zh:rpd:melee_mechanic|近戰武器]] 時傷害可能低於專用武器

===== 數據驗證 =====
  * 資訊來源：Java 枚舉 `com.watabou.pixeldungeon.actors.hero.HeroSubClass.SHAMAN`
  * 機制驗證：HeroSubClass.java 的 attackProc 方法中實現攻擊加成，25% 機率發動魔杖
  * 效果描述：基於 values/strings_all.xml 字串資源 ("HeroSubClass_DescShaman")
  * 名稱驗證：從字串資源確認 ("HeroSubClass_NameShaman")
  * 額外機制：HeroSubClass.java 的 dewBonus 方法中驗證露水加成
