====== 精通 ======

{{ rpd:images:tome_of_mastery_item.png|掌握之书 }}

精通系统允许英雄在击败第二关 BOSS 后选择进阶职业。

==== 解锁条件 ====
  * 使用[[zh:rpd:tome_of_mastery_item|掌握之书]]
  * 在击败天狗后可用
  * 每个职业有两条进阶路径

==== 进阶路径 ====
  * **战士**：[[zh:rpd:gladiator_subclass|角斗士]] 或 [[zh:rpd:berserker_subclass|狂战士]]
  * **法师**：[[zh:rpd:battlemage_subclass|战斗法师]] 或 [[zh:rpd:warlock_subclass|术士]]
  * **潜行者**：[[zh:rpd:assassin_subclass|刺客]] 或 [[zh:rpd:freerunner_subclass|自由奔跑者]]
  * **猎手**：[[zh:rpd:sniper_subclass|狙击手]] 或 [[zh:rpd:warden_subclass|守卫者]]
  * **精灵**：[[zh:rpd:scout_subclass|斥候]] 或 [[zh:rpd:shaman_subclass|萨满]]
  * **死灵法师**：[[zh:rpd:lich_subclass|巫妖]] 或 [[zh:rpd:witch_doctor_subclass|巫医]]
  * **豺狼人**：[[zh:rpd:guardian_subclass|守护者]] 或 [[zh:rpd:witch_doctor_subclass|巫医]]

==== 优势 ====
  * 每个进阶职业拥有独特的能力和机制
  * 在专精领域增强战斗效能
  * 提供额外的游戏策略选择

==== 策略 ====
  * 根据你偏好的游戏风格选择进阶职业
  * 考虑与你职业现有优势的协同效果
  * 进阶职业会显著改变游戏体验
