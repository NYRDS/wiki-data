====== 英雄職業 ======

{{ rpd:images:warrior_hero.png|英雄職業 }}

**英雄職業**決定了玩家在 Remixed Dungeon 中的起始裝備、屬性和特殊能力。每個職業都有獨特的優勢和遊戲風格，使其更適合不同的地下城探索方式。

==== 可用職業 ====
  * [[zh:rpd:warrior_class|戰士]] - 強壯耐久，擁有額外 [[zh:rpd:health_mechanic|生命值]]
  * [[zh:rpd:mage_class|法師]] - 強大的法術和 [[zh:rpd:wands|魔杖]]，食物可為 [[zh:rpd:wands|魔杖]] 充能
  * [[zh:rpd:rogue_class|盜賊]] - 隱秘行動，擁有 [[zh:rpd:invisibility_buff|隱身]] 和額外 [[zh:rpd:gold_item|金幣]]
  * [[zh:rpd:huntress_class|女獵手]] - 遠程戰鬥專家，擁有 [[zh:rpd:bow_item|弓]] 和 [[zh:rpd:arrows_item|箭]]
  * [[zh:rpd:elf_class|精靈]] - 魔法能力，擁有 [[zh:rpd:mana_mechanic|法力]] 系統和特殊的精通路徑
  * [[zh:rpd:necromancer_class|死靈法師]] - 專注於死靈魔法的專門職業
  * [[zh:rpd:gnoll_class|豺狼人]] - 高力量低生命，獨特的遊戲風格
  * [[zh:rpd:priest_class|神父]] - 專注於聖光魔法
  * [[zh:rpd:doctor_class|瘟疫醫生]] - 使用毒氣和骨鋸的特殊職業

==== 職業特徵 ====
  * **起始裝備**: 每個職業開始時擁有特定裝備
  * **特殊能力**: 區分遊戲風格的獨特職業能力
  * **屬性傾向**: 職業在不同領域表現優異
  * **遊戲風格**: 每個職業鼓勵不同的地下城探索方式

==== 職業詳情 ====
  * **戰士**: 起始擁有獨特的武器和護甲，以及一份可食用的口糧。在對抗虛弱敵人時有特殊的治療能力。
  * **法師**: 開始時擁有一根可以作為武器或儲存魔杖的魔法法杖。有快速為物品充能的特殊能力。
  * **盜賊**: 起始擁有獨特的短劍和一組飛刀。在打出強力攻擊後有隱身的特殊能力。
  * **女獵手**: 起始擁有特殊的迴旋鏢和高魔法容量。有為魔杖和法杖充能的特殊能力。
  * **精靈**: 起始擁有特殊的弓和高魔法容量。有為魔杖和法杖充能的特殊能力。免疫纏繞狀態。
  * **死靈法師**: 起始擁有死靈裝備並能召喚不死生物。有暫時控制敵人的特殊能力。
  * **豺狼人**: 起始擁有 15 點力量但只有 5 點生命上限。沒有基礎護甲但擁有獨特的戰斧和飛鏢。其他豺狼不會主動攻擊。
  * **神父**: 起始擁有解詛咒卷軸，專注於聖光魔法。
  * **瘟疫醫生**: 起始擁有瘟疫面具（對所有氣體免疫）和骨鋸。暴擊掉落額外部件，對麻痹敵人造成 +50% 傷害。沒有骨鋸時遭受嚴重命中懲罰。

==== 職業機制 ====
每個英雄職業起始擁有：
  * 獨特的 [[zh:rpd:weapon_item|武器]]
  * 獨特的 [[zh:rpd:armor_item|護甲]]
  * 在特定條件下激活的特殊能力
  * 獨特的 [[zh:rpd:food_item|食物]] 物品

==== 精通路徑 ====
進階玩家可以在用某個職業獲勝後解鎖 [[zh:rpd:hero_subclasses|精通路徑]]（子職業）：
  * 戰士: [[zh:rpd:gladiator_subclass|角鬥士]] 或 [[zh:rpd:berserker_subclass|狂戰士]]
  * 法師: [[zh:rpd:battlemage_subclass|鬥法家]] 或 [[zh:rpd:warlock_subclass|術士]]
  * 盜賊: [[zh:rpd:freerunner_subclass|疾行者]] 或 [[zh:rpd:assassin_subclass|刺客]]
  * 女獵手: [[zh:rpd:warden_subclass|守望者]] 或 [[zh:rpd:sniper_subclass|狙擊手]]
  * 精靈: [[zh:rpd:shaman_subclass|薩滿]] 或 [[zh:rpd:scout_subclass|斥候]]
  * 死靈法師: [[zh:rpd:lich_subclass|巫妖]]
  * 豺狼人: [[zh:rpd:guardian_subclass|守護者]] 或 [[zh:rpd:witchdoctor_subclass|巫醫]]

==== 職業選擇建議 ====
  * **新手玩家**: 戰士通常是最適合初學者的寬容職業
  * **進階玩家**: 每個職業都提供獨特的挑戰和策略
  * **遊戲風格匹配**: 根據偏好的遊戲方式選擇
  * **實驗嘗試**: 嘗試不同職業以找到你的偏好
  * **長期發展**: 考慮職業如何通過多次遊戲發展
